# 월드 레이드 (서버 공유 보스)

서버의 **모든 플레이어가 같은 보스의 체력을 한 주 동안 함께 깎는** 콘텐츠입니다. 주간 보스 화면 왼쪽 아래 `월드 레이드 ▶`(또는 화면 안 `주간 보스로 ▶`로 오감).

- 데이터 · 서버 처리: [ServerRaid.cs](../Assets/_Project/Scripts/Meta/Modes/ServerRaid.cs) · 화면: [ServerRaidScreen.cs](../Assets/_Project/Scripts/Meta/UI/ServerRaidScreen.cs)
- 전투 틀(5분 · 격노 · 결과)은 주간 보스와 같고 **극악 배율**(`WorldRaid.FightWorld`)

| 항목 | 내용 |
|---|---|
| 보스 | **종언의 거신** Lv.100 고정 · 약점 2속성(주마다 바뀜, 주간 보스와 다른 순서) |
| 공유 체력 | **10,000,000,000(100억)**(`ServerRaid.MaxHp` — 튜닝 지점). 모든 플레이어 + **가상 지휘관 1,000명**이 이번 주에 준 피해의 합만큼 깎임. 능력치 10배 뒤 최종 육성 1명이 한 판 약 1.8억 → 그런 플레이어 4명이 하루 2번씩 일주일 치면 쓰러지는 정도(최종 육성 플레이어가 여럿이어도 금방 끝나지 않게, 주간 보스보다 훨씬 크게) |
| 도전 | **하루 2회**(05:00 충전) · **로그인 필요**(게스트는 보기만). 끝까지 싸운 전투만 횟수를 씀(중간에 나가면 기록 · 횟수 모두 없음) |
| 초기화 | 매주 월요일 05:00 — 그때 순위로 보상 |
| 테스트 | 최대 육성 테스트 중에는 도전 횟수 무소모. Server Raid 컴포넌트 ⋮ → `테스트: 도전 횟수 초기화` · `테스트: 지난주 순위 보상 다시 처리` |

## 공유 체력 보상 (참여하지 않아도 모두 받음)

| 깎인 체력 | 보상 |
|---|---|
| 20% | 금화 50,000 · 크리스탈 100 |
| 40% | 대형 경험치 물약 ×10 · 상급 스킬 교본 ×3 |
| 60% | 크리스탈 200 · 장비 정수 100 |
| 80% | 전설의 비전서 ×1 · 재련석 ×1 |
| 100% | 픽업 뽑기권 ×2 · 크리스탈 300 · 재련석 ×1 |

받을 보상이 있으면 홈의 주간 보스 타일에 빨간 느낌표.

순위표의 지휘관을 누르면 지휘관 정보창(전투력 상위 5명 → 캐릭터 상세, [player-info.md](player-info.md)). 월드 레이드 순위에는 실제 플레이어와 **가상 지휘관 1,000명**이 함께 오름(가상 지휘관을 누르면 그 지휘관 정보창).

### 가상 지휘관 (`ServerRaid.VirtualEntries`)

실제 플레이어가 적거나 막 시작한 사람들뿐이어도 공유 체력이 깎이도록, 가상 지휘관들이 함께 싸웁니다.

- 주마다 명단 · 기록이 정해짐(주 키로 계산 — 모든 PC에서 같은 순위표)
- 하루 2번 도전한 것처럼 기록이 **14단계로 계단식**으로 늘고, 4명 중 1명꼴은 주 중간(최대 35% 지점)부터 참여
- 주가 끝날 때 합계 = 최대 체력의 **92%**(`VirtualShare`) → 공유 보상 **4단계(80%)까지는 늘 받음**, 마지막 100%는 실제 플레이어가 나머지 8%(약 8억)를 보태야 함
- 몫은 순위가 높을수록 큼(1위 ≈ 13억, 100위 ≈ 1천만, 1,000위 ≈ 60만). 최종 육성 플레이어(한 주 최대 약 25억)는 1위를 노릴 수 있음
- 순위표: **전체 / 친구** 탭. 전체 = 상위 100명 + (100위 밖이면) 내 위아래 3명, 친구 = 나 + 실제 플레이어 친구 + 가상 친구(지휘관 레벨에 맞춘 기록). 아래에 **내 순위 · 상위 x%** 고정
- 순위 보상에 100위 밖 구간 추가: 상위 10% 크리스탈 80 · 금화 30,000 / 상위 30% 크리스탈 50 · 금화 20,000 / 그 밖 참여자 금화 10,000
- 순위가 높은 가상 지휘관일수록 레벨이 높은 지휘관으로 뽑아, 정보창의 육성 상태가 기록과 어울림
- 지난주 순위 정산에도 가상 지휘관의 최종 기록이 포함됨(순위 보상 구간은 그대로)

## 순위 보상 (지난주 준 피해 순 → 우편함)

| 순위 | 보상 |
|---|---|
| 1위 | 칭호 **종언을 끊어낸 자** · 테두리 `fw_1` · 크리스탈 1,000 · 픽업 뽑기권 ×3 · 재련석 ×2 |
| 2위 | 칭호 **거신을 꺾은 자** · 테두리 `fw_2` · 크리스탈 800 · 픽업 뽑기권 ×2 · 재련석 ×2 |
| 3위 | 칭호 **거신에 맞선 자** · 테두리 `fw_3` · 크리스탈 600 · 픽업 뽑기권 ×2 · 재련석 ×1 |
| 4 ~ 10위 | 크리스탈 400 · 픽업 뽑기권 ×1 · 재련석 ×1 |
| 11 ~ 30위 | 크리스탈 300 · 픽업 뽑기권 ×1 |
| 31 ~ 50위 | 크리스탈 200 · 장비 정수 100 |
| 51 ~ 100위 | 크리스탈 100 · 금화 50,000 |

칭호 · 테두리는 한 번 받으면 계속 씀(프로필). 그림: `Frames/fw_1~3`, 보스 `Enemies/종언의 거신`, 배경 `Backgrounds/worldraid` (`tools/art/art-manifest.js`).

## 서버 구조 (Cloud Save만 사용 — 새 패키지 없음)

각 플레이어가 자기 값을 Cloud Save **공개(Public) 플레이어 데이터**로 올리고, 화면을 열 때(그리고 5분마다) 모두의 값을 **검색(Query)** 해서 더하고 정렬합니다.

| 키 | 내용 |
|---|---|
| `wr_week` · `wr_dmg` · `wr_name` | 이번 주 키(`w20261123`) · 이번 주 준 피해 · 지휘관 이름 |
| `wr_pweek` · `wr_pdmg` · `wr_pname` | 새 주에 처음 올릴 때 옮겨 둔 **지난주** 값(순위 정산용) |

지난주 순위 = (`wr_week` = 지난주) ∪ (`wr_pweek` = 지난주)를 합쳐 정렬. 처음 정산할 때 우편함으로 보상을 보내고 다시 보내지 않음(세이브 `wraid.rankWeek`).

### ⚠ 대시보드에서 한 번 해 주셔야 할 설정 — 검색 인덱스

검색은 인덱스가 있는 키에만 됩니다. Unity Cloud 대시보드 → **Cloud Save → 인덱스 설정**에서 두 개를 만드세요.

1. **플레이어 데이터 · 공개(Public)** 인덱스 — 필드 `wr_week` (오름차순)
2. **플레이어 데이터 · 공개(Public)** 인덱스 — 필드 `wr_pweek` (오름차순)

인덱스가 없으면 화면 순위 칸에 "서버 검색 설정(인덱스)이 없습니다"가 뜹니다. 인덱스를 만들기 **전에** 올린 값은 검색되지 않을 수 있으니, 만든 뒤 한 번 더 전투(또는 `새로고침`)하면 됩니다.

### 알아 둘 점

- 값은 각자 클라이언트가 올리므로, 마음먹으면 조작할 수 있습니다(친구끼리라 이 방식). 공개 서비스로 키우려면 Cloud Code로 서버에서 피해를 검증하는 방식으로 바꿔야 합니다.
- 한 번 검색에 100명씩 최대 1,000명까지 읽습니다.
