## 파견 (방치형 보상)

캐릭터를 정해진 시간 동안 보내 두면 재료를 가져옵니다. 접속하지 않아도 시간이 흐릅니다.

| 항목 | 내용 |
|---|---|
| 의뢰 게시판 | 하루(05:00)마다 새 의뢰 6개. `새 의뢰`(크리스탈 30)로 다시 뽑기 |
| 동시 파견 | 4팀. 한 캐릭터는 한 의뢰에만(파견 중에도 전투 · 육성은 가능) |
| 등급 | C · B · A · S (게시판에 25 · 30 · 30 · 15%) — 최소 레벨 1 · 10 · 25 · 40, **시간 C 1~2 · B 4~6 · A 8~10 · S 12~16시간**, 보상 배율(시간당) 1.0 · 1.6 · 2.4 · 3.2 |
| 크리스탈 | **모든 의뢰에 붙음** — 등급 기본 + 시간당: C 10 + 2 · B 25 + 3 · A 45 + 4 · S 80 + 5 (예: C 1시간 12개 · B 6시간 43개 · A 10시간 85개 · S 16시간 160개), 추천 조건 +50%도 적용. 하루에 고등급 몇 번만 돌려도 충분하도록 기본값을 크게 둠 |
| 인원 | 1 ~ 3명(등급 · 시간에 따라) |
| 추천 조건 | 속성 · 역할(일부 의뢰). 모두 맞추면 **보상 +50%** |
| 주 보상 | 크리스탈 + 금화 · 경험치 재료 · 스킬 교본 · 돌파 재료(의뢰 속성) · 장비 강화석 중 하나 |
| 받기 | 끝나면 `받기` / `모두 받기`. 끝나기 전 `취소`하면 보상 없이 돌아오고 의뢰는 게시판으로 |

- 고르기 창: 추천 조건에 맞는 캐릭터가 앞에 오고 `추천` 표시, 파견 중 · 레벨 부족은 흐리게. `자동 선택` 있음
- 끝난 파견이 있으면 출격 화면 파견 카드 + 홈 출격 버튼에 빨간 느낌표
- 화면(2026-11 개편): 위 = 파견 중 카드 4칸(장소 그림 · 등급 배지 · 그림 아래 남은 시간 막대 · 장소 · 시간 · 보상 종류 아이콘 · 팀 · 보상 · `보상 받기`/`파견 취소`, 빈 칸은 `+ 빈 자리`) · 위 오른쪽 `모두 받기` / 아래 = 의뢰 게시판 3×2 카드(장소 그림 · 등급 · 시간 · 인원 · 레벨 · 추천 조건 · 보상 · `보내기`) · `새 의뢰`
- 장소 그림: `Resources/Art/Dispatch/place_{0~11}.jpg`(art-manifest `dispatch` 그룹, `PlayerDispatch.PlaceIndex` — 장소 순서를 바꾸면 그림도 같이)
- 보상 공식: `PlayerDispatch.RewardOf` — 주 보상 = 시간 × 등급 배율(`GradeMul`) × 추천 보너스, 크리스탈 = (`CrystalBase` + 시간 × `CrystalPerHour`) × 추천 보너스
- 테스트: Player Dispatch 컴포넌트 ⋮ → `테스트: 진행 중인 파견 바로 끝내기` · `테스트: 의뢰 게시판 새로`

## 무한의 탑

1층부터 끝없이 올라가는 도전. 행동력 · 도전 횟수 없이 몇 번이든 도전합니다.

| 항목 | 내용 |
|---|---|
| 적 | 메인 스테이지의 적 유닛을 빌려 층에 맞게 조정. 같은 층은 늘 같은 적. 층이 오를수록 뒤쪽 장의 적이 나옴 |
| 적 수 | 1 ~ 9층 2명 · 10 ~ 29층 3명 · 30층부터 4명 |
| 적 레벨 | 2 + 층 × 0.8 (최대 Lv.80), 보스층 +2 |
| 95층 이후 | 층마다 능력치 +4% (끝없이 강해짐) |
| 보스 | 10층마다. 장 보스 유닛 × 1.3 |
| 첫 클리어 보상 | 금화 2,000 + 150 × 층 · 경험치 재료, 5층마다 크리스탈 40, 10층마다 크리스탈 100 + 스킬 교본 2, 50층마다 픽업 뽑기권 1 |
| 진행 | 이기면 결과 창 `N층 도전`(3초 뒤 자동). 나가면 탑 화면으로 |

- 화면(2026-11 개편): 왼쪽 위 최고 기록 · 다음 보스층 · 10층 단위 진행 막대 / 왼쪽 층 목록(다음 층 + 5층까지 미리 보기 — 층 번호 원 배지, 보스층은 보스 얼굴 · 붉은 줄, 그 층 보상 아이콘 2개, 돌파 · 도전 · 잠김) / 오른쪽 고른 층: 제목 띠(보스층은 붉은색 · 적 레벨 · 능력치 배율) · 약점 속성 칩(`Elements/` 아이콘) · 등장하는 적 카드(속성 아이콘 · 보스는 크게) · 첫 클리어 보상 칸 · 도전
- 이미 깬 층도 다시 도전 가능(보상은 첫 클리어 때만)
- 테스트: Player Tower 컴포넌트 ⋮ → `테스트: 10층 올리기` · `테스트: 탑 기록 초기화`

이미지(스튜디오 생성): `Backgrounds/dispatch` · `Backgrounds/tower` · `Items/DispatchIcon` · `Items/TowerIcon`.
