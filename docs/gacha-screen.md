# 가챠 뽑기 화면

위치: `Assets/_Project/Scripts/Meta/UI/GachaScreen.cs` + `Meta/PlayerWallet.cs`

뽑기 홈 화면 — 위쪽 분류 탭으로 **픽업 뽑기 / 상시 뽑기**를 고르고, 뽑기권 또는 크리스탈로 1회/10연 → 결과 연출 → 로스터 반영.

## 화면

```
 ← 홈  확률 보기        [ 픽업 뽑기 ][ 상시 뽑기 ]          크리스탈 16,000
                                                   픽업 뽑기권 10   상시 뽑기권 10
                    픽업 배너 — 세라핀
              6성 천장까지 90회 · 픽업 배너끼리 공유
  [썸네일 ★6 세라핀]       ┌───────────┐
  [썸네일 ★6 시엘  ]       │ 픽업 캐릭터 │      ← 왼쪽 목록은 픽업일 때만
                           └───────────┘
          [ 1회 뽑기 · 픽업 뽑기권 1 ]  [ 10연 뽑기 · 픽업 뽑기권 10 ]
```

- **픽업 뽑기**: 픽업 캐릭터마다 배너 1개(세라핀 · 시엘). 카드 **왼쪽 세로 목록**(썸네일 + 이름 · 속성)에서 배너 선택 — 화면이 가로로 길어도 카드·제목과 겹치지 않습니다.
- **전환 연출**: 탭을 누르면 선택 탭이 톡 커지며 강조 막대가 붙고, 카드는 옆으로 접혀 사라졌다가(배경 살짝 어두워짐) 새 캐릭터로 펼쳐지며 튕기고, 빛줄기가 카드를 훑은 뒤 이름이 아래에서 떠오릅니다(약 0.5초). 6성의 50%가 픽업, 실패하면 상시 6성 중 1명 + 다음 6성 픽업 확정.
- **상시 뽑기**: 상시 6성 5명(아크 · 오로라 · 카엘 · 바이올렛 · 에스텔) 라인업 표시. 픽업 캐릭터는 나오지 않습니다.
- **천장**: 픽업 배너끼리 공유, 상시는 따로(`gacha_pity_pickup` / `gacha_pity_standard`).

## 비용 — 뽑기권 우선, 없으면 크리스탈

| | 픽업 뽑기 | 상시 뽑기 |
|---|---|---|
| 뽑기권 | **픽업 뽑기권** 1장 = 1회 (10연 = 10장) | **상시 뽑기권** 1장 = 1회 |
| 크리스탈 | 1회 160 · 10연 1,600 | 1회 160 · 10연 1,600 |

- 해당 종류 뽑기권이 **필요한 장수만큼 있으면 뽑기권**, 모자라면 **크리스탈**로 뽑습니다(섞어 쓰지 않음). 버튼과 확인 창에 무엇을 쓰는지 표시.
- 픽업 뽑기권은 상시 뽑기에, 상시 뽑기권은 픽업 뽑기에 쓸 수 없습니다.
- 결과 화면의 `다시 뽑기`도 같은 규칙(확인 창 경유).
- 시작 지급: 픽업·상시 뽑기권 각 10장(새 세이브, 또는 뽑기권 도입 전 세이브에 1회).
- 획득: **임무** — 일일 보너스(상시 1장) · 주간 보너스(픽업 2장 · 상시 3장). [missions.md](missions.md)
- 테스트: 화면 아래 `충전(테스트)` = 크리스탈 +3,200 · 현재 종류 뽑기권 +10. `Meta` → `PlayerWallet` 우클릭 → `뽑기권 테스트 지급`.

## 구성

| 파일 | 역할 |
|---|---|
| `GachaScreen` | 분류 탭 · 픽업 배너 탭 · 미리보기/상시 라인업 · 비용 표시 · 확인 창 |
| `PlayerWallet` | 크리스탈 · 금화 · **픽업/상시 뽑기권** (`Tickets` · `SpendTickets` · `AddTickets`) |
| `GachaController` | 배너 목록(`banners`) · 선택(`Select`) · 천장 묶음별 저장 |
| `GachaResultPanel` | 결과 연출. `SetCostLabel`로 재뽑기 비용 문구(뽑기권/크리스탈) |
| `PlayerRoster` | 뽑은 캐릭터 자동 보유 |

## 비용 튜닝 (인스펙터)

| 필드 | 뜻 |
|---|---|
| `GachaScreen.singleCost` / `multiCost` | 1회/10연 크리스탈 |
| `GachaScreen.chargeAmount` / `chargeTickets` | 테스트 충전량 |
| `PlayerWallet.startingCrystals` / `startingPickupTickets` / `startingStandardTickets` | 시작 지급 |

## 참고

- 배너는 메인 씬 생성기가 만듭니다: `GachaBanner`(픽업 · 세라핀, 예전 배너 에셋 재사용) · `GachaBanner_Pickup2`(픽업 · 시엘) · `GachaBanner_Standard`(상시).
- 메인 씬을 **다시 생성해야** 새 캐릭터·배너가 들어갑니다(예전 씬은 픽업 1개만 보임).
