# 레벨 / 육성 (재료 기반)

위치: `Assets/_Project/Scripts/Meta/` + `Battle/RuntimeUnits.cs`

보유 캐릭터를 **재료 + 금화**로 성장시킵니다. 가챠 재화(크리스탈)와 **별개**입니다. 금화·돌파 재료·돌파 던전: [economy.md](economy.md)

## 세 가지 성장 축

| 축 | 재료 | 효과 |
|---|---|---|
| **레벨업** | 경험치 물약(+500)·경험치 결정(+2500) | 경험치 누적 → 레벨 상승 → HP/ATK/DEF 성장(+6%/Lv) |
| **돌파** | 캐릭터 속성의 돌파 재료(초급/중급/상급) + 금화 | 레벨 상한을 올림 (20 → 40 → 60 → 80) |
| **스킬 레벨업** | 스킬 교본 + 금화 | 스킬 위력 +10%/레벨 (최대 Lv.10) |

## 구성

| 파일 | 역할 |
|---|---|
| `Materials` / `MaterialType` | 재료 종류·이름·경험치값 |
| `PlayerInventory` (MonoBehaviour) | 재료 보유량 + 저장 |
| `Leveling` (static) | 레벨 상한·경험치·스킬 교본 수 |
| `Economy` (static) | 금화 비용, 돌파 재료 종류·개수 |
| `PlayerRoster` | `OwnedCharacter.level/exp/ascension/skillLevel` + `AddExp`·`Ascend`·`UpgradeSkill` |
| `GrowthScreen` (MonoBehaviour) | 육성 화면 — 재료·상세·레벨업/돌파/스킬업 버튼 |
| `RuntimeUnits`·`BattleLauncher` | 전투 시 **보유 레벨·스킬 레벨**을 스탯/위력에 반영 |

## 규칙 (기본값, `Leveling`)

- 레벨 상한: 돌파 0~3 → **20 / 40 / 60 / 80**.
- 필요 경험치: `level → level+1` = `100 × level`.
- 돌파 비용: 40 돌파 초급 ×5 + 금화 5,000 · 60 돌파 중급 ×8 + 15,000 · 80 돌파 상급 ×12 + 30,000 (재료는 캐릭터 속성별).
- 스킬업 비용: 스킬 교본 `현재 스킬레벨` 개 + 금화 1,500 × 현재 스킬레벨.
- 레벨업: 물약/결정 1개당 금화 100 / 500. 합성·초월에도 금화가 듭니다.

## 흐름

1. **레벨업**: 물약/결정 사용 → 경험치 누적 → 상한까지 레벨 상승.
2. **상한 도달** → **돌파**(속성 돌파 재료 + 금화) → 상한 +20 → 다시 레벨업 가능.
3. **스킬업**: 교본 사용 → 스킬 레벨 ↑ → 전투 위력 ↑.
4. 모든 성장치는 로스터(`PlayerPrefs`)에 저장되고, `BattleLauncher`가 **캐릭터별 보유 레벨·스킬 레벨**로 유닛을 만들어 전투에 반영합니다.

## 빠른 체험

메뉴 **`SubcultureRPG > Demo > 육성 데모 생성`** → `GrowthDemo` 씬 → ▶ Play.
- 보유 캐릭터 6종 + 재료(물약/결정/교본) + 금화 지급. 부족하면 **재료·금화 충전(테스트)** 버튼(전 속성 돌파 재료 포함).
- 캐릭터 골라 레벨업 → 상한 도달 시 돌파 → 스킬업. 레벨/스킬이 오르는지, 재료가 소모되는지 확인.
- 올린 뒤 **연동 데모(LinkDemo)** 전투 → 성장한 스탯/위력으로 싸웁니다(저장소 공유).

## 참고 / 확장

- 저작 유닛(`GameDatabase.units`)은 자신의 에셋 스탯을 씁니다(공유 에셋 보호). 생성 유닛(대부분)은 보유 레벨/스킬에 반영.
- 확장: 재료를 전투 보상/상점으로, 캐릭터별 전용 재료, 돌파 시 중복(`count`) 소모, 스킬별 개별 레벨.
