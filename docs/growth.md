# 레벨 / 육성 (재료 기반)

위치: `Assets/_Project/Scripts/Meta/` + `Battle/RuntimeUnits.cs`

보유 캐릭터를 **재료 + 금화**로 성장시킵니다. 가챠 재화(크리스탈)와 **별개**입니다. 금화·재료 등급·특수 던전: [economy.md](economy.md) · 장비: [equipment.md](equipment.md)

## 육성 화면 흐름

1. 홈 → **육성** → 보유 캐릭터 목록(정렬·필터).
2. 캐릭터를 누르면 그 카드가 **회전하며 앞으로 확대**된 뒤 **화면 왼쪽으로 이동**하고, 오른쪽에 상세 화면이 나타납니다.
3. 오른쪽 위: 이름 · 속성 · 역할, `Lv / 상한 · 돌파 · EXP`, **상세 능력치**(장비·초월 포함 실제 전투 수치)
   - 체력 · 공격력 · 방어력 · 속도 · 치명타 확률/피해 · 방어 관통 · 브레이크 효율 · 에너지 회복 · 치유량 · 효과 명중/저항 · 자기 속성 피해
4. 아래 탭 **[레벨 · 장비 · 돌파 · 스킬 · 초월]**에서 육성.
5. 왼쪽 위 `← 목록`을 누르면 카드가 목록 자리로 돌아가며 목록이 다시 나타납니다.

## 탭

| 탭 | 내용 |
|---|---|
| **레벨** | 경험치 재료 4칸(칸 클릭/`+`/`-`), `자동 선택` · `초기화` · `레벨업`. `레벨업`을 눌러야 재료와 금화가 함께 소모. 미리보기 `Lv.15 → Lv.22`, 초과 EXP, 필요 금화. 상한이면 돌파 안내 |
| **장비** | 6부위 장착 현황(세트 · 성급 · 강화 · 주옵션)과 발동 중인 세트 효과, `장비 관리` → 장비 패널(장착·강화·초월·분해) |
| **돌파** | 40 / 60 / 80 돌파 단계(완료 · 현재 · 남음), 현재 단계 조건(레벨 · 속성 재료 · 금화), `돌파` |
| **스킬** | **기본 공격 · 스킬 · 궁극기를 각각 레벨업**(재료로 최대 10, 초월 +2 · +4 · +5에서 재료 없이 각각 +3 → `Lv. 10 +3`). 왼쪽 4번째 칸 **패시브**를 누르면 고유 패시브와 초월 고유 능력(+1 · +3 · +6)을 볼 수 있습니다. 왼쪽에서 스킬을 고르면 오른쪽에 상세: 스킬 이름 · 속성 · 대상, **설명 문장**, **피해/회복 계수(현재 → 다음)**와 현재 공격력 기준 **예상 피해/회복**, 부여 효과(수치 · 지속 턴 · 확률), 브레이크 수치, 에너지 · SP, **Lv.1~10 계수 표**, 필요 재료 · 금화 |
| **초월** | 성급 별, 태생/현재 성급, 중복 장수, 풀 초월까지 남은 장수, 능력치 배율, 초월 고유 패시브, `합성` / `초월` |

## 스킬 레벨업 (개별)

스킬마다 Lv.1 → 10, 레벨당 위력(피해·회복·버프 수치) +10%.
- "다음 레벨" 수치는 공식이 아니라 **실제로 한 레벨 올린 상태를 계산**해 보여 줍니다. 그래서 레벨로 변하지 않는 수치(예: 일부 궁극기의 디버프 %)는 화살표 없이 그대로 표시되고, 계수 표에도 `(레벨로 변하지 않음)`이 붙습니다.
- 표시 수치는 초월 스킬 계수까지 포함한 실제 전투 값입니다. 예상 피해 = 현재 공격력 × 계수 × (1 + 속성 피해 보너스), 적 방어·치명타 적용 전.

| 레벨 | 재료 (등급) | 금화 |
|---|---|---|
| 1 → 2 | 초급 스킬 교본 ×2 (고급 · 초록) | 1,500 |
| 2 → 3 | 초급 스킬 교본 ×3 | 3,000 |
| 3 → 4 | 중급 스킬 교본 ×2 (희귀 · 파랑) | 4,500 |
| 4 → 5 | 중급 스킬 교본 ×3 | 6,000 |
| 5 → 6 | 상급 스킬 교본 ×2 (영웅 · 보라) | 7,500 |
| 6 → 7 | 상급 스킬 교본 ×3 | 9,000 |
| 7 → **8** | 상급 ×4 + **전설의 비전서 ×1** (전설 · 금색) | 10,500 |
| 8 → **9** | 상급 ×5 + **전설의 비전서 ×1** | 12,000 |
| 9 → **10** | 상급 ×6 + **전설의 비전서 ×2** | 13,500 |

- 스킬 1개를 10까지: 초급 5 · 중급 5 · 상급 23 · 비전서 4 · 금화 67,500. 캐릭터 1명(3스킬)은 그 3배.
- 교본은 **스킬 교본 던전** 단계별로 등급이 올라갑니다. **전설의 비전서**는 [상점](shop.md)에서 얻습니다 — 크리스탈 상점(주 2개) · 교환소(상급 교본 ×8 → 1, 주 2회).
- 옛 세이브의 단일 스킬 레벨은 세 스킬 모두 같은 레벨로 옮겨집니다.

## 규칙 (기본값)

| 항목 | 값 |
|---|---|
| 레벨 상한 | 돌파 0~3 → **20 / 40 / 60 / 80** |
| 풀 초월 상한 | **6★ +6(풀 초월) + 돌파 3단계 완료 → Lv.100**. Lv.80부터는 레벨당 필요 경험치 1.5배(80 → 100 약 26.7만 EXP). 능력치는 레벨당 같은 비율로 계속 오름 |
| 필요 경험치 | `level → level+1` = `100 × level` |
| 레벨업 금화 | 들어간 경험치 × 레벨별 단가(Lv.1 100 EXP당 68 → Lv.79 322, Lv.1→80 합계 약 75만) |
| 돌파 | 40 돌파 초급 ×5 + 금화 5,000 · 60 돌파 중급 ×8 + 15,000 · 80 돌파 상급 ×12 + 30,000 (캐릭터 속성 재료) |
| 스킬 | 위 표 (`Leveling.SkillUpgrade`) |
| 합성·초월 | 중복 캐릭터 + 금화 — [transcendence.md](transcendence.md) |

## 구성

| 파일 | 역할 |
|---|---|
| `Materials` / `MaterialType` · `Grades` | 재료 종류·이름·등급(고급/희귀/영웅/전설)·분류·설명 |
| `PlayerInventory` | 재료 보유량 + 저장 |
| `Leveling` (static) | 레벨 상한·경험치·레벨업 금화·**스킬 슬롯과 레벨업 비용** |
| `Economy` (static) | 돌파·합성/초월 금화, 돌파 재료 종류·개수 |
| `PlayerRoster` | `OwnedCharacter.level/exp/ascension/skills[3]` + `AddExp`·`Ascend`·`UpgradeSkill(c, 슬롯)` |
| `GrowthScreen` | 목록 → 카드 연출 → 상세 능력치 + 5탭 |
| `RuntimeUnits`·`BattleLauncher` | 전투 시 보유 레벨·**스킬별 레벨**·성급·초월·장비를 반영 |

**테스트**: 육성 화면 `재료·금화·장비 충전(테스트)` — 경험치 재료 · 초급/중급/상급 교본 · 전설의 비전서 4 · 돌파 재료 · 장비 12개 · 금화 10만. `선택 캐릭 중복 +6(테스트)`는 상세 화면에서 누르세요.

**밸런스 테스트용 최대 육성(임시)**: 육성 화면 `전체 최대 육성(테스트)` ([TestMaxData.cs](../Assets/_Project/Scripts/Meta/TestMaxData.cs))

- 적용 전 세이브 전체를 이 PC의 `persistentDataPath/test-max-backup.json`에 백업 → 버튼이 빨간 `원래 세이브로 되돌리기(테스트)`로 바뀜. 누르면 백업으로 되돌리고 게임을 다시 불러옴(그 사이 진행은 사라짐)
- 테스트 중(백업이 있는 동안)에는 **주간 보스 도전 횟수를 쓰지 않음**(주간 보스 화면에 "최대 육성 테스트 중 · 소모 안 함")
- 원래 끼던 장비는 빼서 가방에 남김. 로그인 중이면 최대 육성 상태도 서버에 저장되고, 되돌리면 원래 세이브가 다시 올라감
