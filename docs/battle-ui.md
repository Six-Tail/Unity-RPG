# 전투 UI (HUD)

위치: `Assets/_Project/Scripts/Battle/UI/` (+ 공용 `Assets/_Project/Scripts/UI/UIFactory.cs`)

`BattleController`의 이벤트에 붙어 전투 화면을 코드로 구성합니다. 프리팹/씬 배치 불필요 — 컴포넌트 하나가 Canvas·패널·바·버튼을 만듭니다.

## 구성

| 파일 | 역할 |
|---|---|
| `BattleHUD` (MonoBehaviour) | 전투 화면 전체 — 팀 배치·턴 순서 바·스킬/대상 입력·피해 숫자·승패 |
| `UnitPanel` (MonoBehaviour) | 유닛 1명 패널 — 이름·HP 바·에너지 바·현재 턴/대상 하이라이트·격파 |
| `UIFactory` (`SubcultureRPG.UI`) | 코드 uGUI 공용 헬퍼(가챠 UI와 별개의 공용 버전) |

## 세팅 (2단계)

1. 빈 GameObject에 **BattleHUD** 추가 → `controller`에 `BattleController` 연결(비우면 자동 탐색), `font`에 CJK TMP 폰트.
2. 플레이 → `BattleController`가 전투를 시작하면 HUD가 자동으로 그려집니다.

(가챠 UI와 동일하게 TMP Essentials 임포트 + 한글 폰트가 필요합니다. `docs/gacha-ui.md` 참고.)

## 조작

- **내 차례**: 하단에 스킬 버튼이 나타납니다. 스킬 클릭 →
  - 단일 대상: 적이 여럿이면 "대상을 선택하세요" → 적 패널 클릭. 적이 하나면 자동 발동.
  - 전체 대상(AllEnemies): 즉시 발동.
  - 필살기: 에너지가 가득 찼을 때만 활성화.
  - **스킬 포인트(SP)**: 스킬은 SP 1 소모, 기본 공격은 SP +1. SP가 0이면 스킬 버튼이 비활성화됩니다(화면 하단 'SP 표시' 참고). 그래서 기본 공격으로 SP를 적립하는 운영이 필요합니다.
- **적/자동 턴**: 스스로 진행.
- **자동 전투 / 배속** (우상단 버튼, 설정은 다음 전투에도 유지):
  - `자동 ON/OFF`: 내 턴도 AI가 진행. 내 차례에 켜면 그 턴부터 바로 자동.
  - `배속 ×1/×2/×3`: 누를 때마다 ×1 → ×2 → ×3 → ×1. 턴 간 대기 시간을 줄임. 허브에서는 **챕터 1 클리어 = ×2, 챕터 3 클리어 = ×3** 해금(잠긴 단계에 닿으면 해금 조건 안내 후 ×1). 독립 전투 씬은 처음부터 ×3까지 사용 가능.
  - 아군 AI(`BattleEngine.PickAutoAction`): HP 50% 미만 아군 회복 → 필살기 → 스킬(SP 2 이상, 또는 약점·버프처럼 확실히 이득일 때) → 기본 공격. 대상은 약점(미브레이크) > 마무리 가능 > 낮은 체력 순.
- **턴 순서 바**(상단): 다가올 행동 순서. 맨 앞이 다음 차례(밝게 표시).
- **승패**: 마지막 타격 후 바로 끊기지 않고 **마무리 연출**(아래)을 거쳐 결과 화면이 서서히 나타납니다. 결과 화면 버튼: `전투 기록` · `다시` · (나가기) · (다음).
- **전투 기록 창**(`BattleStatsPanel`): 결과 화면의 `전투 기록`을 누르면 아군·적 유닛별로 **준 피해(막대 + 숫자) · 받은 피해 · 회복량 · 치명 · 브레이크 · 격파**를 보여 줍니다. 위쪽에 총 행동 횟수 · 아군 피해/회복 합계 · 적 피해 합계, 아군 중 준 피해 1위에 `MVP`. 쓰러진 유닛은 회색 + `쓰러짐`. 피해 · 회복은 **실제로 깎이고 채워진 양**(쓰러뜨릴 때 남은 체력을 넘은 피해, 가득 찬 체력을 넘은 회복은 빼고 셈 — 전투 중 뜨는 숫자는 그대로). 유닛 이름은 전투 시작 때 저장해 두므로 전투 뒤 정리되는 적(주간 보스 등)도 이름 · 그림이 나옵니다. 창이 열리면 `다음 스테이지` 자동 진행 카운트다운이 멈춥니다(버튼은 그대로). 바깥 어두운 곳이나 `닫기`로 닫힘.
  - 기록은 `BattleUnit.record`(`BattleRecord`)에 엔진이 쌓습니다. 피해·회복은 화면에 뜬 숫자 기준(초과분 포함), 지속 피해는 효과를 건 유닛의 준 피해로 계산됩니다.

- **패시브 · 추가 행동 표시**: 패시브가 발동하면 그 유닛 위에 `패시브 · 이름`이 뜹니다. 추가 공격·반격은 본 타격이 끝난 뒤 머리말(`추가 공격` · `반격`)이 붙은 숫자로, 흡혈·재생·패시브 회복은 초록 숫자로 표시됩니다. 기절한 유닛의 턴에는 `행동 불가`가 뜨고 턴이 넘어갑니다. 캐릭터별 구성은 [character-kits.md](character-kits.md).
- **이펙트 구현**: `SkillFx` — 움직임은 코드 파티클, 모양은 생성한 **이펙트 텍스처 20장**(`Resources/Art/Fx`, 흰색 + 투명도라 속성 색을 곱해 모든 속성에 공용). 텍스처가 없으면 예전 코드 도형(Glow · Ring · Beam · Triangle · Star)으로 그림. 텍스처 생성: `tools/art/generate-fx.js`(검은 배경 흰 빛으로 그린 뒤 밝기를 투명도로), 목록: [fx-textures.jpg](fx-textures.jpg). 유닛 줄 위 레이어에 그리고, 피해 숫자는 그 위 `Popups` 레이어에 그려 이펙트에 가리지 않습니다. 배속이 빠를수록 이펙트도 빨라집니다.
- **버프 · 디버프 아이콘**: 유닛 패널 바로 아래에 걸린 효과가 아이콘으로 나열됩니다(버프 먼저, 그다음 디버프).
  - 아이콘 그림(`Resources/Art/Status/`, 6종) + **테두리 색** = 버프 청록 · 디버프 빨강 · 지속 피해 보라 · 브레이크 주황. 칼 = 공격력, 방패 = 방어력, 초록 ↑ = 증가, 빨강 ↓ = 감소, 해골 물방울 = 지속 피해, 깨진 방패 = 브레이크.
  - 오른쪽 아래 숫자 = **남은 턴**(그 유닛의 턴이 시작될 때마다 1 감소). 브레이크는 다음 자기 턴에 풀리므로 숫자가 없습니다.
  - 아이콘을 **누르면 설명 창**: 효과 이름 · 버프/디버프 · 대상 이름 / 내용(`공격력 +25%`, `자기 턴이 시작될 때마다 피해 120`) / 남은 턴. 같은 아이콘이나 설명 창을 다시 누르면 닫히고, 효과가 끝나면 자동으로 닫힙니다. 창이 열린 동안 남은 턴이 실시간으로 갱신됩니다.
  - 그림 파일이 없으면 색 바탕 + 글자(`공` · `방` · `독` · `B`) + 화살표 아이콘으로 대신 표시됩니다. 그림은 `node tools/art/generate-art.js --only status`로 다시 만들 수 있습니다([art.md](art.md)).
- **속성 아이콘**: 모든 유닛 패널의 초상 왼쪽 위 모서리에 그 유닛의 속성이 동그란 아이콘으로 표시됩니다(속성 색 + 이름 첫 글자 `물`·`화`·`얼`·`번`·`바`). `Resources/Art/Elements/{Physical|Fire|Ice|Lightning|Wind}.png`가 있으면 속성 색 테두리의 둥근 칸에 그 그림을 씁니다(`node tools/art/generate-art.js --only status`로 생성).
- **약점 줄**: 적 패널 바로 위 왼쪽에 `약점` + 그 적의 약점 속성 아이콘들이 항상 표시됩니다.
- **브레이크 게이지**: 적 패널의 에너지 바 아래 흰색 바(`남은 양/최대`). **어떤 공격이든 깎이지만 약점 속성으로 때리면 약 3배 많이** 깎입니다(`BattleConfig.breakRateWeak` 1.0 / `breakRateNormal` 0.35). 0이 되면 브레이크 → 바가 비고 붉은 `BREAK`, 그 적의 다음 턴에 다시 가득 찹니다.
- **약점 어시스트**: 아군이 행동을 고르는 동안, **그 아군의 속성이 약점인 적** 패널 위 오른쪽에 `속성 아이콘 + 약점!` 표시가 속성 색으로 맥동하고, 약점 줄의 해당 아이콘도 커집니다. 행동이 끝나거나 자동 전투를 켜면 사라집니다.
- **스킬 버튼**: `종류(기본 공격·스킬·궁극기) 이름` / `대상 · 피해 180%` 같은 효과 / `SP -1` 같은 비용을 함께 표시.
- **턴 순서 바**: 이름 두 글자 대신 **초상화**(없으면 글자), 테두리 = 아군 파랑 · 적 빨강, 맨 앞(다음 차례)은 크게.
- 현재 행동 유닛은 금색, 선택 가능한 대상은 붉게 깜빡이는 테두리.
- 행동 직전 연출 시간은 `BattleController.OnActionStarting`에서 HUD가 `PresentationDelay`로 요청합니다(배속이 높으면 짧아짐. 궁극기 컷인은 읽을 수 있게 덜 줄어듦: ×1 1.4초 · ×2 약 1초 · ×3 약 0.8초).
- 연출은 `Time.unscaledDeltaTime` 기반이라 일시정지 중에도 재생됩니다.

## 확장 포인트

- **포트레이트/배경**: `UnitPanel`은 `CharacterData.thumbnail`을 표시합니다. 전투 배경 아트는 `drawBackground`를 끄고 뒤에 배치.
- **스킬 설명/쿨다운/코스트 표시**: `BuildSkillButtons`에서 버튼에 추가.
- **대형 연출(필살기 컷인 등)**: `HandleResolved`에서 스킬별로 분기해 연결.
- **6성 Live2D 등장**: `CharacterViewFactory`로 모델을 띄워 전투 포트레이트를 대체 가능.

## 총 피해량 (오른쪽 위)

모든 전투(스테이지 · 던전 · 결투장 · 주간 보스)에서 아군 캐릭터의 턴 동안 그 캐릭터가 적에게 준 피해 합계를 오른쪽 위(자동 · 배속 버튼 아래)에 `총 피해량`으로 표시합니다.

- 개별 피해 숫자는 지금처럼 적 위에 뜨고, 여기에는 합계만 나옵니다.
- 다단 히트 · 브레이크 추가 피해 · 연쇄 시전 · 그 캐릭터의 추가 공격까지 더합니다(회복 · 다른 아군의 추가 공격은 제외).
- 숫자는 빠르게 굴러 올라가며 피해가 들어올 때마다 살짝 튑니다. **마지막 피해 뒤 1.8초 동안** 그대로 보이고 사라집니다(턴이 빨리 넘어가도 바로 0이 되거나 사라지지 않음).
- 다음 아군 캐릭터는 **그 캐릭터의 첫 피해가 들어오는 순간** 새로 셉니다(0이 화면에 보이지 않음).
- 구현: [TurnDamageCounter.cs](../Assets/_Project/Scripts/Battle/UI/TurnDamageCounter.cs)

## 턴 표시 (행동 순서 줄 왼쪽)

`N 턴` — 살아 있는 모든 아군 · 적이 한 번씩 행동하면 다음 턴(`BattleEngine.Round` · `RoundChanged`). 스테이지 전투에서는 옆에 `/ ★3 N턴` 기준을 함께 표시하고, 기준을 넘기면 회색으로 바뀝니다.

## 전투 필드 (2.5D) — 1단계

카드 줄 대신, 배경 위에 아군(왼쪽)과 적(오른쪽)이 **서 있는** 필드입니다. 피해 숫자 · 이펙트는 각 유닛의 가슴 높이에 뜹니다.

| 요소 | 내용 |
|---|---|
| 유닛 그림 | 아군 = `Art/Figures/{id}`(전신, 발끝까지) → 없으면 `Art/Cutouts/{id}`(허벅지까지, 아래를 부드럽게 흐림) → 초상. 적 = `Art/Enemies/{이름}` |
| 배치 | 아군 4자리 · 적 5자리(앞줄이 아래, 뒤로 갈수록 작게). 보스(적 1명이거나 체력이 다른 적의 1.8배 이상)는 크게, 가운데 뒤 |
| 발밑 | 그림자 · 고리(차례 = 금색, 대상 고르기 = 빨강 맥동, 궁극기 준비 = 금빛 맥동) |
| 머리 위 | 이름 · 속성 · 체력(숫자) · 에너지(아군) / 내구도(적) · 약점 · 상태 아이콘 |
| 대기 | 숨쉬기(위아래 · 세로로 아주 살짝), 차례인 유닛은 앞으로 한 발 |
| 공격 | 한 명을 노리면 대상 앞까지 **돌진** → 타격 → 복귀. 광역 · 지원은 제자리에서 한 발. 스킬은 차지 이펙트 후 |
| 피격 | 그림이 하얗게(치명 = 금색, 약점 = 분홍) **번쩍** + 뒤로 **밀려남** |
| 히트스톱 | 치명 · 브레이크 0.06초, 궁극기 0.09초 동안 모든 유닛이 멈춤 |
| 카메라 | 스킬 = 시전자 쪽 살짝 확대, 궁극기 = 맞는 쪽으로 확대 + 필드 어둡게, 치명 · 브레이크 = 살짝 당김. 기존 화면 흔들림과 함께 |
| 쓰러짐 | 적 = 번쩍인 뒤 사라짐, 아군 = 어둡게 남음 |
| 아래 왼쪽 | **파티 바**: 초상 · 이름 · 체력 · 에너지 · `궁극기 준비` · 차례 금색 테두리 · 전투 불능. 누르면 아군 대상 고르기 |
| 아래 오른쪽 | **원형 행동 버튼**(기본 · 스킬 · 궁극기, 크기 차이), 위에 스킬 포인트 점. 버튼에 손을 올리거나 대상을 고르는 동안 설명 창 |
| 위 | 행동 순서 · 턴 · 안내 문구(행동 순서 아래) |
