# 길드 (실제 플레이어 길드 + 가상 길드 · 길드 보스 · 길드전 · 순위)

친구끼리 가볍게 즐기는 용도라, **플레이어가 만든 실제 길드와 가상 길드를 함께** 씁니다. 길드 보스 · 길드전의 상대와 순위표에는 가상 길드가 늘 함께 나옵니다.

- 길드 상태: [PlayerGuild.cs](../Assets/_Project/Scripts/Meta/Social/PlayerGuild.cs) · 가상 길드: [VirtualGuilds.cs](../Assets/_Project/Scripts/Meta/Social/VirtualGuilds.cs) · 순위: [GuildRanking.cs](../Assets/_Project/Scripts/Meta/Social/GuildRanking.cs)
- 서버 동기화: [GuildLink.cs](../Assets/_Project/Scripts/Meta/Cloud/GuildLink.cs)
- 길드 보스: [GuildBoss.cs](../Assets/_Project/Scripts/Meta/Modes/GuildBoss.cs) · 길드전: [GuildWar.cs](../Assets/_Project/Scripts/Meta/Modes/GuildWar.cs)
- 화면: `GuildScreen`([SocialScreens.cs](../Assets/_Project/Scripts/Meta/UI/SocialScreens.cs)) · 길드 채팅: [ChatService.cs](../Assets/_Project/Scripts/Meta/Social/ChatService.cs)

## 설정 (한 번) — UGS 대시보드

Cloud Save ▸ **Queries(인덱스)** 에 3개 추가 — 모두 **Player · Public · 문자열(string)**:

| 키 | 쓰임 |
|---|---|
| `g_id` | 길드원 찾기(이 길드 id를 내건 플레이어) |
| `g_open` | 추천 · 검색(`"1"` = 모집 중) · 순위표(`"0"` 이상 = 모든 플레이어 길드) |
| `g_req` | 길드장이 받은 가입 신청 찾기 |

인덱스가 없으면 길드 화면에 "서버 검색 설정(Cloud Save 인덱스 g_id · g_open · g_req)이 없어…"라고 나오고 가상 길드만 보입니다.

## 실제 길드 · 가상 길드

| | 실제 길드(플레이어) | 가상 길드 |
|---|---|---|
| 만들기 | 로그인 중에 `길드 창설`(금화 50,000, 이름 2 ~ 8자, 가입: 자유 / 승인 후) | 로그인하지 않았을 때 창설(가상 길드원 5명과 시작) |
| 가입 | `길드 찾기` 탭의 플레이어 길드 — 자유 가입이면 바로, 승인제면 `가입 신청` → 길드장 수락 | 추천 가상 길드 8곳(날마다 · 새로고침) — 바로 |
| 길드원 | 실제 플레이어(최대 30명) | 가상 지휘관 |
| 길드 경험치 | 길드원 누적 기여도의 합(길드장이 계산) | 출석 · 기부 + 가상 길드원이 날마다 쌓음 |
| 길드 채팅 | 있음(Vivox 채널 `stella_guild_{길드 id}`, 채팅 창 `길드 채팅`) | 없음 |
| 로그인 | 필요(게스트는 가상 길드만) | 필요 없음 |

공통: 출석(하루 1번, 금화 5,000 × (1 + 길드 레벨당 10%) + 크리스탈 10, 기여도 +20) · 기부(하루 3번, 금화 10,000 → 크리스탈 5, 기여도 +50) · 길드 레벨 최대 10(다음 레벨까지 1,000 × 레벨).

### 길드장(실제 길드)

- `가입 신청` 탭: 받은 신청 수락 · 거절, 모집 설정(자유 가입 ↔ 승인제 · 소개 바꾸기 · 가입 조건 레벨)
- `길드원` 탭: 길드원 `추방`
- `해산`: 길드장이 나가면 길드가 해산됩니다(**길드장 위임은 다음 버전**). 길드원은 다음 동기화 때 자동으로 나가지고 알림을 받음

### 서버 데이터(서버 함수 없이 각자 자기 Cloud Save 공개 데이터만 씀)

| 키 | 누가 씀 | 내용 |
|---|---|---|
| `g_info` | 길드장 | 이름 · 소개 · 가입 방식 · 가입 조건 · **길드원 목록** · 추방/거절 목록 · 길드 경험치 · 이번 주 길드 보스 피해 · 길드전 별 |
| `g_open` | 길드장 | `"1"` 모집 중 · `"0"` 정원 가득 · `""` 길드 없음 |
| `g_id` | 모든 길드원 | 내가 속한 길드 id(= 길드장 플레이어 id) |
| `g_req` | 가입 신청자 | 신청한 길드 id |
| `g_st` | 모든 길드원 | 이번 주 기여도 · 누적 기여도 · 길드 보스 피해 · 길드전 상대별 별 |

- 승인제 가입: 신청자가 `g_req`를 올림 → 길드장이 수락하면 `g_info` 목록에 넣음 → 신청자가 다음 동기화 때 보고 가입 완료(`g_id`)
- 자유 가입: 가입하는 사람이 바로 `g_id`를 올림 → 길드장이 다음 동기화 때 목록에 넣음(정원이 넘치면 거절 목록 → 그 사람은 나가지고 알림)
- 탈퇴는 `g_id`를 비움 → 길드장이 다음 동기화 때 목록에서 뺌. 추방 · 해산은 길드원이 다음 동기화 때 알아챔
- 동기화: 로그인 중 2분마다, 길드 화면이 열려 있으면 30초마다. 길드와 상관없는 플레이어는 아무것도 올리지 않음

## 길드 보스 (주간 · 협동)

길드마다 **종말의 군주** 1마리. 길드원이 준 피해를 한 주 동안 합쳐 체력을 깎고, 다 깎으면 다음 단계로.

| 항목 | 내용 |
|---|---|
| 도전 | 하루 2회(05:00 충전), 끝까지 싸운 전투만 횟수를 씀. 전투 틀(5분 · 30초마다 격노)은 주간 보스와 같음 |
| 단계 | 1단계 체력 5,000만, 단계마다 ×3(최대 10단계). 1단계 쉬움 Lv.30 → 2단계 보통 Lv.50 → 3단계 어려움 Lv.80 → 4단계부터 극악 Lv.100(이후 단계마다 방어 +12%) |
| 길드 합계 | 실제 길드 = 길드원들이 올린 이번 주 피해의 합 · 가상 길드 = 나 + 가상 길드원이 날마다 보탠 피해 |
| 단계 보상 | 길드가 깬 단계마다 길드원 각자 `받기`: 금화 3만 · 크리스탈 50 · 대형 경험치 물약 ×5 · 크리스탈 100 · 상급 스킬 교본 ×3 · 크리스탈 150 · 장비 정수 80 · 전설의 비전서 · 크리스탈 200 · 픽업 뽑기권 |
| 순위 보상 | 주가 바뀌면 지난주 길드 순위(길드 보스 탭)로 우편: 1위 크리스탈 500 · 2~3위 300 · 4~10위 200 · 11~30위 120 · 31~100위 80 · 그 밖 40(+ 금화). 이번 주에 한 번이라도 싸웠을 때만 |

## 길드전 (주간 PVP · 상대는 가상 길드)

| 항목 | 내용 |
|---|---|
| 상대 | 매주 가상 길드 1곳(실제 길드도 상대는 가상 길드). 상대 길드원 10명이 방어 팀을 둠 — 강함은 **내 주력 4명 전투력의 55% ~ 132%**(번호가 클수록 강함). 결투장 가상 상대와 같은 규칙(레벨 · 초월 · 스킬)으로 맞추고, 최대(Lv.100 · +6)로도 모자라면 장비 대신 보정(체력 · 공격 · 방어 %)을 더 올림. 주마다 한 번 만들어 두고 그 주 동안 그대로 |
| 공격 | 하루 3회(05:00 충전). 이기면 별 — 아군 모두 살아남음 ★3 · 절반 이상 ★2 · 그 밖 ★1 |
| 길드 별 | 상대 길드원별로 우리 길드원이 얻은 **최고 별의 합**(최대 30). 상대 길드도 날마다 우리를 공략해 별이 쌓임 |
| 결과 | 월요일 05:00에 별이 많은 쪽 승리 → 우편: 승리 크리스탈 150 · 금화 5만 · 장비 정수 40 / 무승부 크리스탈 90 · 금화 3만 / 패배 크리스탈 50 · 금화 2만(이번 주에 별을 하나라도 얻었을 때) |

## 길드 순위

`순위` 탭(가입 전에도 볼 수 있음): **길드 보스(이번 주 피해) · 길드전(이번 주 별) · 길드 레벨(경험치)**. 가상 길드 200곳 + 플레이어 길드(서버, 3분마다 갱신) + 우리 길드가 한 표에. 우리 길드는 맨 위에 한 번 더 표시.

- **서버 자동 시험**(실제 길드 · 인덱스 필요, Unity를 닫고 배치로): `Unity.exe -batchmode -projectPath . -executeMethod SubcultureRPG.EditorTools.GuildCloudTest.RunBatch -guildCloudOut <폴더>`
  ([GuildCloudTest.cs](../Assets/_Project/Scripts/Editor/GuildCloudTest.cs)). 빈 씬으로 플레이 모드에 들어가(타이틀 · 로그인이 뜨지 않아 내 계정은 로그인 안 됨) 시험용 익명 플레이어 A · B를 만들어
  실제 코드로 창설 → 검색 → 승인제 신청 → 수락 → 길드원 · 기록 확인 → 순위표 → 추방 → 자유 가입 → 해산을 돌리고, 끝나면 두 플레이어의 공개 데이터를 비우고 계정을 삭제 · 내 세이브의 길드 기록 복원
  - 2026-11-26 결과: 22개 모두 통과(인덱스 g_id · g_open · g_req 확인)
- 실제 길드는 계정 두 개(다른 기기 · 에디터 + 빌드)로: 한 쪽이 창설 → 다른 쪽이 `길드 찾기`에서 가입 → 2분 안에(길드 화면을 열면 30초 안에) 서로 보임
