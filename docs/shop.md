# 상점

홈 → **상점**. 위쪽 탭 `일반 상점 · 크리스탈 상점 · 교환소`, 왼쪽 상품 칸(테두리 = 아이템 등급 색), 오른쪽 상세 + 수량 선택(`-10 · - · + · +10 · 최대`) + 구매.

- 상품 칸: 등급 · 남은 구매 횟수(`오늘 3/5`, `이번 주 1/2`, `무제한`) · 지급 수 · 가격 띠. 품절이면 흐려지고 `품절`, 재화가 모자라면 가격이 흐려집니다.
- 상세: 용도 · 보유 수(교환소는 교환 재료 보유 수도) · 남은 구매 · 합계(획득 / 가격). 살 수 없으면 버튼에 사유(`금화가 부족합니다`, `구매 제한에 도달했습니다` …).
- **크리스탈 결제는 확인 창**을 거칩니다(가챠와 같은 방식). 금화·재료는 바로 구매.
- 상단 안내 줄에 **다음 초기화까지 남은 시간**.

## 초기화

| 주기 | 시각 (로컬) |
|---|---|
| 매일 | **05:00** |
| 매주 | **월요일 05:00** |

`ShopCatalog.ResetHour`로 시각 조정. 05:00 이전은 전날로 칩니다.

## 상품

### 일반 상점 — 금화 · 매일

| 상품 | 1회 | 가격 | 하루 |
|---|---|---|---|
| 소형 경험치 물약 | ×10 | 금화 1,500 | 5 |
| 경험치 물약 | ×5 | 금화 4,000 | 5 |
| 대형 경험치 물약 | ×3 | 금화 10,000 | 3 |
| 초급 스킬 교본 | ×3 | 금화 3,000 | 3 |
| 중급 스킬 교본 | ×2 | 금화 8,000 | 3 |
| 상급 스킬 교본 | ×1 | 금화 15,000 | 2 |
| 장비 강화석 | ×10 | 금화 5,000 | 5 |
| 소형 행동력 물약 | ×1 | 금화 8,000 | 2 |
| 들꽃 꽃다발 (호감도 +50) | ×2 | 금화 5,000 | 3 |
| 수제 쿠키 상자 (호감도 +150) | ×1 | 금화 12,000 | 2 |

### 크리스탈 상점 — 크리스탈 · 매주

| 상품 | 1회 | 가격 | 주간 |
|---|---|---|---|
| 금화 50,000 | ×1 | 크리스탈 100 | 5 |
| 경험치 결정 | ×3 | 크리스탈 120 | 3 |
| 별빛 브로치 (호감도 +400) | ×1 | 크리스탈 60 | 5 |
| 상급 스킬 교본 | ×3 | 크리스탈 150 | 3 |
| **전설의 비전서** | ×1 | 크리스탈 300 | 2 |

(가챠 1회 = 크리스탈 160 기준으로 잡은 값)

### 교환소 — 재료 → 재료

| 교환 | 제한 |
|---|---|
| 상급 스킬 교본 ×8 → **전설의 비전서** ×1 | 주 2회 |
| 돌파 재료 **초급 ×3 → 중급 ×1** (같은 속성, 5속성) | 무제한 |
| 돌파 재료 **중급 ×3 → 상급 ×1** (같은 속성, 5속성) | 무제한 |

→ 전설의 비전서는 이제 상점에서 주 최대 4개(크리스탈 2 + 교환 2)까지 얻을 수 있습니다.

## 코드

| 파일 | 역할 |
|---|---|
| [ShopCatalog.cs](../Assets/_Project/Scripts/Meta/Shop/ShopCatalog.cs) | 상품 목록 · 탭 이름 · 초기화 시각 (튜닝 지점) |
| [PlayerShop.cs](../Assets/_Project/Scripts/Meta/Shop/PlayerShop.cs) | 구매(값 차감 → 지급 → 제한 기록) · 남은 횟수 · 초기화 주기 · `PlayerPrefs("shop")` 저장 |
| [ShopScreen.cs](../Assets/_Project/Scripts/Meta/UI/ShopScreen.cs) | 상점 화면(코드로 UI 구성) |

- 상품 `id`는 세이브 키입니다. 바꾸면 그 상품의 구매 기록이 사라집니다(삭제된 상품의 기록은 불러올 때 버림).
- 구매 기록 초기화: `Meta` 오브젝트의 `PlayerShop` 우클릭 → `상점 구매 기록 초기화`.
- 상점 도입 전에 만든 `Main.unity`도 그대로 동작합니다 — 씬에 `ShopScreen`이 없으면 `ScreenNavigator`가 실행 중에 만들고(홈 화면 폰트 사용), `PlayerShop`이 없으면 지갑 오브젝트에 붙입니다. 메인 씬을 다시 생성하면 둘 다 씬에 들어갑니다.
