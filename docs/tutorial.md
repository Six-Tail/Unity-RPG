# 튜토리얼 · 기능 개방

구현: [Tutorial.cs](../Assets/_Project/Scripts/Meta/UI/Tutorial.cs) (씬에 내비게이터가 있으면 스스로 만들어짐). 진행 상황은 PlayerPrefs `tutorial.step` · `tutorial.flag.*`.

## 신규 지휘관 튜토리얼

화면을 막지 않습니다. 눌러야 할 곳을 **금색 테두리**로 표시하고 말풍선으로 안내하며, 말풍선의 `튜토리얼 건너뛰기`로 언제든 그만둘 수 있습니다.

| 단계 | 내용 |
|---|---|
| 0 환영 | 타이틀 · 이름 정하기가 끝나고 홈에 오면 환영 알림(`시작하기` / `건너뛰기`) |
| 1 첫 전투 | 홈 `스테이지` → 스테이지 화면 `편성 후 출격` → 편성 화면 `출격` 순서로 테두리 안내. 1-1 전투가 시작되면 전투를 멈추고 **전투 기본** 설명(행동 순서 · 스킬 포인트 · 약점과 브레이크 · 턴과 별 3개 · 자동/배속) |
| 2 레벨업 | 1-1을 깨고 전투에서 나오면 **첫 승리!** 알림 → `육성으로 이동`. 육성 화면에서 ① `자동 선택` ② `레벨업` 테두리 안내. 경험치 물약이 하나도 없으면 소형 물약 5개, 금화가 2,000 미만이면 3,000을 채워 줌 |
| 완료 | 육성 화면에서 성장 행동(레벨업 등)을 하면 완료 → 우편으로 보상(크리스탈 300 · 금화 20,000 · 경험치 물약 ×10) |

- 스토리가 나오는 동안에는 안내를 숨깁니다.
- 튜토리얼을 넣기 전부터 하던 세이브(1-1을 이미 깬 경우)는 조용히 완료 처리합니다.
- 건너뛰면 완료 보상은 없습니다. 말풍선의 `튜토리얼 건너뛰기` 버튼 옆에 `건너뛰면 완료 보상을 받을 수 없어요` 경고가 있고, 누르면 확인 창에서 빨간 경고와 받지 못하는 보상 내용을 한 번 더 보여 줍니다(`Tutorial.CompleteReward`).
- 가리킬 대상이 아직 화면에 없으면(예: 육성 화면에서 캐릭터를 고르기 전) 말풍선을 화면 **아래 가운데**에 띄워 위쪽 필터 · 목록을 가리지 않습니다.
- 테스트: Tutorial 컴포넌트 ⋮ → `테스트: 튜토리얼 처음부터` · `테스트: 기능 개방 · 화면 설명 다시 보기`

## 기능 개방

스테이지(쉬움)를 진행하면 차례로 열리고, 열릴 때마다 홈이나 스테이지 화면에서 알림이 한 번 뜹니다(`바로 가기` 버튼).

| 조건 | 열리는 것 |
|---|---|
| 1장 클리어 | 특수 던전: 경험치 · 금화 · 스킬 교본 던전 |
| 2장 클리어 | 장비 던전 |
| 3장 클리어 | 돌파 던전 · **결투장(PVP)** · **주간 보스** |
| 난이도 조건 | 하드 · 극악 난이도 |

- 결투장 · 주간 보스는 3장을 깨기 전에는 홈 타일이 어둡게 잠기고 `3장 클리어 시 개방`이라고 표시됩니다. 눌러도 안내만 뜹니다(`FeatureGate`, [ChapterStarRewards.cs](../Assets/_Project/Scripts/Meta/Rewards/ChapterStarRewards.cs) 아래쪽).
- 던전 개방 조건은 스테이지 데이터(`unlockAfter`)가 정합니다.

## 처음 들어간 화면 설명

가챠 · 임무 · 상점 · 길드 · 친구 화면은 처음 들어갈 때 한 번씩 간단한 설명이 뜹니다.

## 화면에 대상 등록하기

튜토리얼이 가리킬 버튼은 화면이 만들 때 `TutorialTargets.Set("키", 버튼)`으로 등록합니다. 지금 등록된 키: `home.stage` · `home.growth` · `stage.sortie` · `party.start` · `growth.auto` · `growth.confirm`.
