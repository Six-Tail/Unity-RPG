# 금화 · 돌파 재료 · 특수 던전

| 재화/재료 | 용도 | 획득처 |
|---|---|---|
| 크리스탈 | 가챠 | 스테이지·던전 **첫 클리어 1회** |
| **금화** | 레벨업 · 돌파 · 스킬 · 합성/초월 · 장비 강화 — 육성에 **반드시** 필요 | **금화 던전** · 메인 스테이지 · 돌파 던전 (매 클리어) |
| 경험치 재료 4종 (+100 / +500 / +1,000 / +5,000) | 레벨업 | 메인 스테이지 · **경험치 던전** (매 클리어) |
| 스킬 교본 3종 (초급 · 중급 · 상급) | 스킬 레벨업(스킬별) | **스킬 교본 던전** (단계별 등급) |
| 전설의 비전서 | 스킬 Lv.8 · 9 · 10 | **상점** (크리스탈 상점 · 교환소) · **기간 한정 이벤트**(누적 보상 · 이벤트 상점) |
| 장비 강화석 | 장비 강화 | **장비 던전** · 장비 분해 · 상점 |
| **속성별 돌파 재료** | 돌파 (40 / 60 / 80) | **돌파 던전** (해당 속성·등급) · 상점 교환소 (하위 ×3 → 상위 ×1) |

경험치 재료·스킬 교본은 **상점**에서도 금화(매일)·크리스탈(매주)로 보충할 수 있습니다 — [shop.md](shop.md).

코드: [Materials.cs](../Assets/_Project/Scripts/Meta/Materials.cs) (재료 종류·이름) · [Economy.cs](../Assets/_Project/Scripts/Meta/Economy.cs) (금화·돌파 비용) · [PlayerWallet.cs](../Assets/_Project/Scripts/Meta/PlayerWallet.cs) (크리스탈·금화)

## 아이템 등급

모든 재료와 장비는 4등급으로 나뉘고, 가방·장비·던전에서 같은 색으로 표시됩니다.

| 등급 | 색 | 장비 성급 | 재료 |
|---|---|---|---|
| **고급** | 초록 | 3★ | 소형 경험치 물약 · 초급 스킬 교본 |
| **희귀** | 파랑 | 4★ | 경험치 물약 · 중급 스킬 교본 · 장비 강화석 · 돌파 재료 초급 |
| **영웅** | 보라 | 5★ | 대형 경험치 물약 · 상급 스킬 교본 · 돌파 재료 중급 |
| **전설** | 금색 | 6★ | 경험치 결정 · 전설의 비전서 · 돌파 재료 상급 |

코드: `Grades`(이름·색) · `Materials.Grade(재료)`.

## 돌파 재료 (속성 5종 × 등급 3종 = 15종)

돌파 단계마다 **다른 재료**가 필요하고, 단계가 오를수록 등급이 올라갑니다.

| 속성 | 초급 — 40 돌파 | 중급 — 60 돌파 | 상급 — 80 돌파 |
|---|---|---|---|
| 물리 | 단련의 파편 | 단련의 결정 | 단련의 핵 |
| 화염 | 불씨 조각 | 화염 결정 | 홍염의 핵 |
| 얼음 | 서리 조각 | 빙결 결정 | 영구동토의 핵 |
| 번개 | 전하 조각 | 뇌광 결정 | 천둥의 핵 |
| 바람 | 바람 조각 | 질풍 결정 | 폭풍의 핵 |

- 캐릭터는 **자기 속성**의 재료만 씁니다 (예: 화염 캐릭터 60 돌파 = 화염 결정).
- 세이브 호환: 재료 값은 `100 + 속성×10 + 등급`. 예전 공용 `돌파석`은 삭제했습니다(옛 세이브의 보유량은 불러올 때 제거, 값 2는 재사용 금지).

## 금화 비용

| 육성 | 재료 | 금화 |
|---|---|---|
| 레벨업 | 경험치 재료 (선택해서 투입) | 들어간 경험치 × 레벨별 단가 (아래) |
| 40 돌파 (Lv.20 → 40) | 속성 초급 재료 ×5 | 5,000 |
| 60 돌파 (Lv.40 → 60) | 속성 중급 재료 ×8 | 15,000 |
| 80 돌파 (Lv.60 → 80) | 속성 상급 재료 ×12 | 30,000 |
| 스킬 Lv.N → N+1 | 교본 N개 | 1,500 × N |
| 합성 → 4★ / 5★ / 6★ | 중복 | 10,000 / 20,000 / 40,000 |
| 초월 +1 … +6 | 중복 | 30,000 … 80,000 (+1만씩) |

### 레벨업 금화 (레벨이 높을수록 비쌈)

`Leveling.GoldPerExp(레벨) = 0.65 × (1 + 레벨/20)` — 경험치 1당 금화 (`GoldPerExpBase` = 0.65).

| 레벨 | 100 EXP당 금화 | 한 레벨 올리는 금화 |
|---|---|---|
| Lv.1 | 68 | 68 |
| Lv.20 | 130 | 2,600 |
| Lv.40 | 195 | 7,800 |
| Lv.60 | 260 | 15,600 |
| Lv.79 | 322 | 25,418 |

| 구간 | 금화 |
|---|---|
| Lv.1 → 20 | 약 20,000 |
| Lv.20 → 40 | 약 97,000 |
| Lv.40 → 60 | 약 226,000 |
| Lv.60 → 80 | 약 406,000 |
| **Lv.1 → 80 합계** | **약 750,000** (경험치 316,000) |
- 상한을 넘어 버려지는 경험치에는 금화가 들지 않습니다.

수치는 `Economy`(돌파·스킬·합성)와 `Leveling.GoldPerExp`(레벨업)에서 조정합니다. 금화가 부족하면 버튼이 꺼지고 비용이 빨갛게 표시됩니다.

## 특수 던전

홈 **`출격`** → `스토리 · 스테이지` → 화면 맨 위 **`특수 던전`** 탭 → 종류 탭(장비 · 돌파 · 경험치 · 금화 · 스킬 교본) → 왼쪽 세로 목록에서 단계 선택(화면 구성: [stages.md](stages.md#특수-던전-화면)). 모두 반복 도전 가능, 별 평가는 메인 스테이지와 같고 `다음 스테이지로`는 없습니다.

| 종류 | 구성 | 주 보상 |
|---|---|---|
| **돌파 던전** | 속성 5 × 초급/중급/상급 | 속성 돌파 재료 |
| **경험치 던전** | 1~10단계 | 경험치 재료 |
| **금화 던전** | 1~10단계 | 금화 |
| **스킬 교본 던전** | 1~10단계 | 스킬 교본(단계별 등급) |
| **장비 던전** | 세트 2종씩 5곳(지도에서 장소 선택) × 1~10단계 (낮은 단계 = 1 · 2★ 위주, 높을수록 고성급) | 장비 · 장비 강화석 — [equipment.md](equipment.md) |

- 금화 던전: 황금 정령 2 + **황금 골렘**(단단함, 약점 번개·얼음). 스킬 교본 던전: 떠도는 마도서 2 + **금서의 파수꾼**(약점 화염·물리).

### 경험치 던전 (개방·적 레벨은 위와 같음)

같은 시점(개방 챕터) 메인 스테이지의 **행동력당 경험치 × 약 2배**. 메인 스테이지는 금화 · 크리스탈 · 캐릭터 경험치도 같이 주므로, 경험치만 모을 때는 던전이 확실히 낫도록 맞춤(이전 값은 메인과 거의 같아 던전을 돌 이유가 없었음).

**비교 기준**(행동력당, 같은 시점 메인 스테이지 = 그 챕터 6스테이지 평균): 금화 던전 금화 3.4 ~ 5배(초반 단계가 더 후함 — 신규 지휘관 금화 부족 완화, 그대로 둠) · 경험치 던전 경험치 약 2배(조정) · 스킬 교본 던전은 캐릭터 1명 스킬 3개 Lv.10(상급 69개)을 10단계 약 10회(행동력 190)로 모음 · 장비 던전은 장비 2개 + 강화석(그대로).

- 적: 경험의 정령 2 + 지혜의 고목(약점 화염·바람).

### 돌파 던전

속성(행) × 등급(열) 15칸.

| 등급 | 개방 조건 | 적 레벨 | 매 클리어 보상 | 첫 클리어 |
|---|---|---|---|---|
| 초급 | 메인 **3-6** 클리어 | Lv.14~16 | 초급 재료 ×3 · 금화 3,000 · EXP 400 | 크리스탈 30 |
| 중급 | 메인 **6-6** 클리어 | Lv.34~36 | 중급 재료 ×3 · 금화 8,000 · EXP 1,500 | 크리스탈 50 |
| 상급 | 메인 **10-6** 클리어 | Lv.52~54 | 상급 재료 ×4 · 금화 15,000 · EXP 3,500 | 크리스탈 80 |

- 캐릭터 1명 돌파당 던전 횟수: 40 돌파 2회 · 60 돌파 3회 · 80 돌파 3회.
- 적: 속성 정령 2 + 수호자 1. 약점은 그 속성을 상대하기 좋은 두 속성이라, **다른 속성 파티**로 도는 게 유리합니다.

| 던전 | 약점 |
|---|---|
| 물리 | 번개 · 화염 |
| 화염 | 얼음 · 바람 |
| 얼음 | 화염 · 물리 |
| 번개 | 바람 · 얼음 |
| 바람 | 물리 · 번개 |

- 메인 스테이지 상세에 `클리어 시 개방 · 돌파 던전 초급 / 금화 던전 2단계`처럼 표시됩니다.
- 던전 수치는 `StageContent.Dungeon()`에서, 개방 스테이지는 `StageContent.Build()`의 `unlockBy`에서 바꿉니다.

**테스트**: 육성 화면 `재료·금화 충전(테스트)` (전 속성 돌파 재료 + 금화 10만), Wallet ⋮ `금화 테스트 지급`.
