# 금화 · 돌파 재료 · 돌파 던전

| 재화/재료 | 용도 | 획득처 |
|---|---|---|
| 크리스탈 | 가챠 | 스테이지·던전 **첫 클리어 1회** |
| **금화** | 레벨업 · 돌파 · 스킬 · 합성/초월 (이후 장비 강화 등) — 육성에 **반드시** 필요 | 메인 스테이지 · 돌파 던전 (매 클리어) |
| 경험치 물약 / 결정 | 레벨업 | 메인 스테이지 (매 클리어) |
| 스킬 교본 | 스킬 레벨업 | 돌파 던전 (매 클리어) |
| **속성별 돌파 재료** | 돌파 (40 / 60 / 80) | **돌파 던전** (해당 속성·등급) |

코드: [Materials.cs](../Assets/_Project/Scripts/Meta/Materials.cs) (재료 종류·이름) · [Economy.cs](../Assets/_Project/Scripts/Meta/Economy.cs) (금화·돌파 비용) · [PlayerWallet.cs](../Assets/_Project/Scripts/Meta/PlayerWallet.cs) (크리스탈·금화)

## 돌파 재료 (속성 5종 × 등급 3종 = 15종)

돌파 단계마다 **다른 재료**가 필요하고, 단계가 오를수록 등급이 올라갑니다.

| 속성 | 초급 — 40 돌파 | 중급 — 60 돌파 | 상급 — 80 돌파 |
|---|---|---|---|
| 물리 | 단련의 파편 | 단련의 결정 | 단련의 핵 |
| 화염 | 불씨 조각 | 화염 결정 | 홍염의 핵 |
| 얼음 | 서리 조각 | 빙결 결정 | 영구동토의 핵 |
| 번개 | 전하 조각 | 뇌광 결정 | 천둥의 핵 |
| 바람 | 바람 조각 | 질풍 결정 | 폭풍의 핵 |

- 캐릭터는 **자기 속성**의 재료만 씁니다 (예: 화염 캐릭터 60 돌파 = 화염 결정).
- 세이브 호환: 재료 값은 `100 + 속성×10 + 등급`. 기존 공용 `돌파석`은 더 이상 쓰이지 않습니다(보유량은 남아 있음).

## 금화 비용

| 육성 | 재료 | 금화 |
|---|---|---|
| 레벨업 | 물약 1개 (+500 EXP) / 결정 1개 (+2500 EXP) | 100 / 500 (경험치 5당 1) |
| 40 돌파 (Lv.20 → 40) | 속성 초급 재료 ×5 | 5,000 |
| 60 돌파 (Lv.40 → 60) | 속성 중급 재료 ×8 | 15,000 |
| 80 돌파 (Lv.60 → 80) | 속성 상급 재료 ×12 | 30,000 |
| 스킬 Lv.N → N+1 | 교본 N개 | 1,500 × N |
| 합성 → 4★ / 5★ / 6★ | 중복 | 10,000 / 20,000 / 40,000 |
| 초월 +1 … +6 | 중복 | 30,000 … 80,000 (+1만씩) |

수치는 `Economy`에서 조정합니다. 금화가 부족하면 버튼이 꺼지고 비용이 빨갛게 표시됩니다.

## 돌파 던전

스테이지 화면의 **`돌파 던전`** 탭 — 속성(행) × 등급(열) 15칸. 반복 도전 가능하며, 별 평가는 메인 스테이지와 같습니다.

| 등급 | 개방 조건 | 적 레벨 | 매 클리어 보상 | 첫 클리어 |
|---|---|---|---|---|
| 초급 | 메인 **1-3** 클리어 | Lv.14~16 | 초급 재료 ×3 · 교본 1 · 금화 3,000 · EXP 400 | 크리스탈 30 |
| 중급 | 메인 **2-3** 클리어 | Lv.30~32 | 중급 재료 ×3 · 교본 2 · 금화 6,000 · EXP 1,200 | 크리스탈 50 |
| 상급 | 메인 **2-6** 클리어 | Lv.48~50 | 상급 재료 ×4 · 교본 3 · 금화 10,000 · EXP 2,500 | 크리스탈 80 |

- 캐릭터 1명 돌파당 던전 횟수: 40 돌파 2회 · 60 돌파 3회 · 80 돌파 3회.
- 적: 속성 정령 2 + 수호자 1. 약점은 그 속성을 상대하기 좋은 두 속성이라, **다른 속성 파티**로 도는 게 유리합니다.

| 던전 | 약점 |
|---|---|
| 물리 | 번개 · 화염 |
| 화염 | 얼음 · 바람 |
| 얼음 | 화염 · 물리 |
| 번개 | 바람 · 얼음 |
| 바람 | 물리 · 번개 |

- 메인 스테이지 상세에 `클리어 시 개방 — 돌파 던전 초급`처럼 표시됩니다.
- 던전 수치는 `MainSceneGenerator.Dungeon()`에서, 개방 스테이지는 `BuildStages()`의 `unlockBy`에서 바꿉니다.

**테스트**: 육성 화면 `재료·금화 충전(테스트)` (전 속성 돌파 재료 + 금화 10만), Wallet ⋮ `금화 테스트 지급`.
