# 스테이지 · 전투 보상

홈 → **스테이지** → 스테이지 선택 → **편성 후 출격** → 파티 선택 → **출격!** → 전투 → 결과(별 평가 + 보상) → **스테이지로**

## 해금 · 별 평가

- 진행 순서상 **앞 스테이지를 클리어하면 다음 스테이지가 열립니다** (난이도마다 따로 진행, 각 난이도 1-1은 난이도 개방 시 열림).
- 별(최고 기록 유지):

| 별 | 조건 |
|---|---|
| ★1 | 클리어 |
| ★2 | 아군 전원 생존 |
| ★3 | `StarRoundLimit`**턴** 이내 클리어. 턴 = 살아 있는 모든 아군 · 적이 한 번씩 행동하면 1턴(빠른 유닛은 한 턴에 여러 번 행동 가능). 기본 = (`turnLimit` + 2) ÷ 4 올림, 메인 스테이지는 장별 여유(1 ~ 2장 +2 · 3 ~ 5장 +1 · 6장부터 0)를 더함. 예: 1-1 4턴 · 1-6 6턴 · 8-1 3턴 · 15-6 5턴 |

## 보상

| 종류 | 지급 |
|---|---|
| 크리스탈 | **첫 클리어 1회만** (반복 파밍으로 무한 획득 방지) |
| 금화 · 경험치 재료(1~3챕터 물약·소형 물약, 4~8챕터 대형 물약·물약, 9~15챕터 결정·대형 물약) | 클리어할 때마다 (돌파 재료·교본은 **특수 던전**에서 — [economy.md](economy.md)) |
| 캐릭터 경험치 | 클리어할 때마다, **출전한 캐릭터 전원** (레벨 상한이면 돌파 필요) |

- 패배: 보상 없음.
- 결과 화면 버튼: `다시` · `스테이지로` · **`다음 스테이지로`** (승리 시, 메인 스테이지만).
  - `다음 스테이지로`는 **5초 뒤 자동 진행**(버튼에 남은 초 표시) — 같은 파티로 바로 출격. `다시`/`스테이지로`를 누르면 취소.
  - 마지막 스테이지·특수 던전·패배 시에는 표시되지 않습니다. 시간은 `StageRunner.autoNextSeconds`(0 = 자동 진행 끔).
  - `스테이지로`를 누르면 마지막으로 싸운 스테이지가 선택된 상태로 돌아옵니다.
- 결과 화면 `다시`로 재도전해도 다시 평가·지급됩니다.

## 행동력 · 보상 배수 · 반복 입장

규칙 한 곳: [StageEntry.cs](../Assets/_Project/Scripts/Meta/Stages/StageEntry.cs) · 행동력 보관: `PlayerWallet.Stamina`

- **행동력**: 최대 240, 실시간으로 **6분마다 1** 회복(게임을 꺼 둬도 흐름). 충전으로 최대치를 넘길 수 있고(최대 999) 그동안은 회복이 멈춥니다.
- **행동력 물약**: `소형 행동력 물약`(+60) · `행동력 물약`(+120). 사용하면 최대치를 넘겨 쌓을 수 있고(최대 999), 넘으면 `380 / 240`처럼 금색으로 표시되며 **넘은 동안 자연 회복(6분당 1)은 멈춥니다**. 240 아래로 쓰면 그때부터 다시 회복.
  - 사용: 스테이지 화면 행동력 알약의 `+`, 또는 가방(기타 탭)에서 물약 선택 → `사용`. 수량을 골라 한 번에 여러 개 사용, 사용 후 수치 미리보기.
  - 획득: 일반 상점(소형 · 금화 8,000 · 매일 2개), 크리스탈 상점(일반 · 크리스탈 60 · 매주 6개). 수치: `Materials.StaminaValue`.
- **입장 비용**: 입장할 때 차감, **패배하거나 도중에 나가면 전부 반환**.

| 스테이지 | 행동력 |
|---|---|
| 메인 쉬움 / 하드 / 극악 | 6 / 8 / 10 |
| 돌파 던전 | 초급 10 · 중급 12 · 상급 14 |
| 금화 · 교본 · 경험치 던전 | 10 + 단계마다 1 (1단계 10 … 10단계 19) |
| 장비 던전 | 15 + 단계마다 1 (1단계 15 … 10단계 24) |

- **보상 배수 x1 · x2 · x3** (★3으로 클리어한 **메인 스테이지 · 특수 던전**): 행동력을 배수만큼 쓰고, 매 클리어 보상(금화 · 재료 · 캐릭터 경험치 · 장비 드롭 수)을 배수만큼 받습니다. 첫 클리어 크리스탈은 배수 없음.
- **반복 입장** (같은 조건): `끔 · 3회 · 5회 · 10회 · 최대`. 승리하면 결과 화면에서 3초 뒤 같은 던전 · 같은 파티로 자동 재입장하고, 반복 중에는 자동 전투가 켜집니다. 횟수를 다 쓰거나, 패배하거나, 행동력이 모자라면 멈춥니다. `최대` = 행동력이 떨어질 때까지.
- **소탕** (같은 조건): 상세 패널 아래 `소탕 1회` · `소탕 N회`(행동력 · 소탕권이 되는 만큼, 최대 10회). 전투 없이 바로 결과 창이 뜹니다.
  - 소탕 1회마다 **소탕권 1장** + 행동력(보상 배수를 올려도 소탕권은 1장). 소탕권 획득처: 일일 임무 '게임 접속' ×5 · 주간 임무 '전투 20회 승리' ×10 · 일반 상점(×5 금화 3,000, 하루 2번) · 크리스탈 상점(×20 크리스탈 40, 주 3번) · 신규 지휘관 환영 선물 ×20.
  - 행동력 · 보상 배수는 전투와 같고, 금화 · 재료 · 장비 · 지휘관 경험치를 받습니다. **캐릭터 경험치는 없음**(출전 파티가 없어서).
  - 임무에는 1회마다 전투 승리(특수 던전이면 던전 클리어도) 1회로 셉니다. 호감도는 오르지 않습니다(전투 승리만).
  - 코드: `StageRunner.Sweep` · `SweepAffordable` · `MaxSweep` · `SweepTicketCost`, 버튼은 `StageScreen.RefreshSweep`. 테스트: 육성 화면 `재료·금화·장비 충전(테스트)`에 소탕권 30장 포함.
- 배수 · 반복 설정은 던전 공용으로 기억됩니다. 스테이지 상세 패널 아래쪽에서 고르고, 출격 버튼에 이번 입장 행동력이 표시됩니다(부족하면 `행동력 부족`으로 잠김).
- 결과 화면의 `다시` · `다음 스테이지로`도 행동력을 확인합니다. 부족하면 버튼 위에 이유가 뜹니다.
- 테스트: 스테이지 화면 오른쪽 위 `행동력 +120 (테스트)` 또는 Player Wallet 컴포넌트 ⋮ → `행동력 테스트 충전`.

테스트: 스테이지 화면 오른쪽 위 `3장까지 클리어 (테스트)` — 쉬움 1 ~ 3장의 모든 스테이지를 별 3개로 클리어 처리(첫 클리어 보상 · 스토리는 건너뜀). 결투장 · 주간 보스 · 월드 레이드 · 이벤트 · 파견 · 무한의 탑이 바로 열림(새 테스트 계정용).

- 수치는 `StageContent`의 공식에서 바꾼 뒤 메뉴 `SubcultureRPG > 메인 스테이지 데이터 다시 생성`을 실행하면 270개 에셋이 갱신됩니다(진행도 그대로 · 하드 적 레벨 공식이 바뀌면 에디터를 열 때 자동 실행).
  쉬움 = `Demo/Stages/Stage_c-n.asset`, 하드 = `Stages/Hard/`, 극악 = `Stages/Hell/`.

## 메인 스토리 화면

```
 ← 홈        [ 메인 스토리 ][ 특수 던전 ]                    행동력
 [쉬움][하드][극악]
 [1][2][3] … [15]                                  ← 챕터 바로 가기
 ┌ CHAPTER 1 · 그림자 숲   ★ 18/18 ━━★━★━★ [별 보상] ┐ ┌ 1-1 숲의 입구 ────┐
 │                                    ( 6 BOSS )      │ │ 권장 Lv · 기록      │
 │ <        ( 4 )                                   > │ │ 적 구성(그림 카드)   │
 │    ( 2 )  ·  ·  ·      ( 5 )                       │ │ 별 조건(받은 별 금색) │
 │ ( 1 ) ·  ·  ( 3 )                                  │ │ 보상(아이콘)        │
 │  ★★★   ★★★   진행 중                               │ │ 배수 · 반복 · 출격   │
 └────────────────────────────────────────────────────┘ └──────────────────┘
```

- **챕터 지도**: 챕터 전투 배경 그림(`Backgrounds/battle_ch{N}`) 위에 스테이지 6개가 길을 따라 이어집니다. 깬 스테이지까지의 길은 금색 점선, 그 뒤는 흐린 점선.
- **스테이지 동그라미**: 테두리 금색 = 클리어 · 하늘색 + 위에 `진행 중` 깃발(위아래로 살짝 움직임) = 지금 깰 차례 · 회색 = 잠김. 아래 알약에 받은 별(빈 별은 어둡게), 그 아래 스테이지 이름. 깼지만 ★3이 아니면 위에 `★3 도전`.
- **보스(6)**: 더 크고 빨간 테두리 + 동그라미 안에 보스 그림 + `BOSS` 표.
- **위쪽 띠**: `CHAPTER N`(난이도) · 챕터 이름 · `★ 지금 / 최대` + 다음 보상 별 수 · 진행 막대(12 · 15 · 18 보상 지점 별 표시, 달성하면 밝게) · `별 보상`(받을 것이 있으면 느낌표). 테두리 색 = 난이도(하드 주황 · 극악 빨강).
- **양옆 `<` `>`**: 이전 · 다음 챕터(다음 챕터가 아직 잠겨 있으면 꺼짐). 위쪽 챕터 번호 줄로도 바로 이동.
- **오른쪽 상세**: 권장 레벨 · 최고 기록 → 적 구성(그림 · 레벨 · 약점 카드) → 별 조건 3줄(받은 별만큼 금색 + `달성`) → 보상 아이콘(첫 클리어 크리스탈 · 금화 · 경험치 재료) + 출전 캐릭터 경험치 → 클리어 시 열리는 특수 던전. 내용이 길면 위아래로 끌어서 봄. 아래는 행동력 · 보상 배수 · 반복 입장 · 출격 · 소탕(그대로).
- 코드: [StageScreen.Main.cs](../Assets/_Project/Scripts/Meta/UI/StageScreen.Main.cs) — 스테이지 위치는 `NodePos`.

## 특수 던전 화면

스테이지 화면 맨 위 가운데 탭 **`메인 스토리` / `특수 던전`** 으로 둘을 나눕니다(코드: [StageScreen.cs](../Assets/_Project/Scripts/Meta/UI/StageScreen.cs) · [StageScreen.Dungeon.cs](../Assets/_Project/Scripts/Meta/UI/StageScreen.Dungeon.cs)).

```
 ← 홈            [ 메인 스토리 ][ 특수 던전 ]                         행동력
 [장비][돌파][경험치][금화][스킬 교본]          ← 던전 종류
 [물리][화염][얼음][번개][바람]  /  [< 지도][장소 5곳]   ← 돌파 = 속성, 장비 = 장소
 ┌ 단계 목록 ┐ ┌ 던전 그림 · 이름 · 권장 레벨 ┐ ┌ 상세 ─────────┐
 │ 10단계 ★★★│ │ 매 클리어 보상(아이콘)      │ │ 설명 · 별 조건 · 보상 │
 │  9단계 ★★ │ │ 적 구성(그림 카드 · 약점)    │ │ 보상 배수 · 반복 입장 │
 │  …        │ │ (장비: 드롭 성급 막대 · 세트) │ │ 편성 후 출격 · 소탕   │
 └───────────┘ └────────────────────────────┘ └───────────────┘
```

- **단계 목록**(왼쪽 세로): 단계 · 대표 보상 · 권장 레벨 · 행동력 · 별(잠긴 단계는 개방 조건). 처음 열면 **열린 단계 중 가장 높은 단계**가 골라집니다.
- **장비 던전**: 종류 탭을 누르면 지도 → 장소(핀 또는 오른쪽 목록) → 단계 목록 순서([equipment.md](equipment.md#장비-던전-특수-던전-탭)).
- **돌파 던전**: 속성 탭 5개 + 초급 · 중급 · 상급.
- 전투에서 돌아오면 하던 던전(종류 · 장소 · 속성 · 단계)이 그대로 골라져 있습니다.
- 단계 데이터는 `Assets/_Project/Demo/Stages/Dungeon_*.asset`(생성: `StageContent.BuildDungeons`, 메뉴 `SubcultureRPG > 특수 던전 데이터 다시 생성`).
