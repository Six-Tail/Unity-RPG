# 스테이지 · 전투 보상

홈 → **스테이지** → 스테이지 선택 → **편성 후 출격** → 파티 선택 → **출격!** → 전투 → 결과(별 평가 + 보상) → **스테이지로**

## 구성 요소

| 파일 | 역할 |
|---|---|
| [StageData.cs](../Assets/_Project/Scripts/Meta/Stages/StageData.cs) | 스테이지 1개 (SO). 적(유닛 + 레벨), 권장 레벨, ★3 행동 제한, 보상 |
| [StageDatabase.cs](../Assets/_Project/Scripts/Meta/Stages/StageDatabase.cs) | 스테이지 목록 + 챕터 이름 + 난이도 개방 챕터. 진행 순서 = (난이도별) 챕터, 번호 |
| [StageProgress.cs](../Assets/_Project/Scripts/Meta/Stages/StageProgress.cs) | 최고 별·클리어 횟수 저장 (PlayerPrefs `stages`), 해금 판정 |
| [StageRunner.cs](../Assets/_Project/Scripts/Meta/Stages/StageRunner.cs) | 출격(적 레벨 적용) → 종료 시 별 평가·보상 지급·결과 표시 |
| [StageScreen.cs](../Assets/_Project/Scripts/Meta/UI/StageScreen.cs) | 난이도·특수 던전 탭 · 챕터 번호 / 던전 종류 탭 · 스테이지 노드 · 상세 패널 UI |
| [StageContent.cs](../Assets/_Project/Scripts/Editor/StageContent.cs) (에디터) | 15챕터 × 3난이도 + 던전 데이터 생성, 적 레벨·보상 **공식** |

- 적은 같은 유닛 에셋을 **레벨만 바꿔** 재사용합니다(실행 중 복제본 사용, 원본 에셋 그대로). 데모 적은 레벨당 능력치 +7%.
- 편성 화면은 스테이지에서 들어오면 **출격 모드**(제목 `출격 준비 · 1-3 …`, 버튼 `출격!`, 뒤로 `← 스테이지`)로 엽니다. (홈의 연습 전투 메뉴는 삭제)

## 해금 · 별 평가

- 진행 순서상 **앞 스테이지를 클리어하면 다음 스테이지가 열립니다** (난이도마다 따로 진행, 각 난이도 1-1은 난이도 개방 시 열림).
- 별(최고 기록 유지):

| 별 | 조건 |
|---|---|
| ★1 | 클리어 |
| ★2 | 아군 전원 생존 |
| ★3 | 아군 행동 `turnLimit`회 이내 클리어 |

## 보상

| 종류 | 지급 |
|---|---|
| 크리스탈 | **첫 클리어 1회만** (반복 파밍으로 무한 획득 방지) |
| 금화 · 경험치 재료(1~3챕터 물약·소형 물약, 4~8챕터 대형 물약·물약, 9~15챕터 결정·대형 물약) | 클리어할 때마다 (돌파 재료·교본은 **특수 던전**에서 — [economy.md](economy.md)) |
| 캐릭터 경험치 | 클리어할 때마다, **출전한 캐릭터 전원** (레벨 상한이면 돌파 필요) |

- 패배: 보상 없음.
- 결과 화면 버튼: `다시` · `스테이지로` · **`다음 스테이지로`** (승리 시, 메인 스테이지만).
  - `다음 스테이지로`는 **5초 뒤 자동 진행**(버튼에 남은 초 표시) — 같은 파티로 바로 출격. `다시`/`스테이지로`를 누르면 취소.
  - 마지막 스테이지·특수 던전·패배 시에는 표시되지 않습니다. 시간은 `StageRunner.autoNextSeconds`(0 = 자동 진행 끔).
  - `스테이지로`를 누르면 마지막으로 싸운 스테이지가 선택된 상태로 돌아옵니다.
- 결과 화면 `다시`로 재도전해도 다시 평가·지급됩니다.

### 난이도

| 난이도 | 개방 | 적 레벨 | 적 능력치 | 보상 (금화·경험치) | 첫 클리어 크리스탈 |
|---|---|---|---|---|---|
| **쉬움** | 처음부터 | 기본 | ×1 | ×1 | ×1 |
| **하드** | 쉬움 **7챕터** 클리어 | +8 | ×1.25 | ×1.6 | ×1.5 |
| **극악** | 쉬움 **15챕터** 클리어 | +16 | ×1.6 | ×2.5 | ×2 |

- 스테이지 화면 위쪽 버튼으로 난이도 전환(잠긴 난이도는 `(7챕터 클리어)`처럼 표시). 개방 순간 결과 화면에 `하드 난이도 개방!`.
- 개방 챕터는 `StageDatabase.hardUnlockChapter` / `hellUnlockChapter` (현재 쉬움 기준).
- ★3 행동 제한은 하드 +1, 극악 +2회 여유.

### 공식 (`StageContent`)

| 항목 | 쉬움 기준 |
|---|---|
| 적 레벨 | `1 + (챕터-1)×5.4 + (스테이지-1)` → 1-1 Lv.1 · 4-1 Lv.17 · 7-6 Lv.38(보스 40) · 10-6 Lv.55 · 15-6 Lv.82(보스 84) |
| 금화 | `(1,000 + 600×(챕터-1)) × (1 + 0.1×(스테이지-1))`, 보스 ×1.8 → 1-1 1,000 · 15-6 약 16,900 |
| 경험치 재료(총 EXP) | `(1,000 + 1,000×(챕터-1)) × 같은 배율` → 1-1 1,000 · 15-6 약 27,000 |
| 첫 클리어 크리스탈 | 1~5챕터 60 · 6~10 80 · 11~15 100 (보스 160 / 240 / 300) |

| 한 번씩 전부 클리어 | 금화 | 경험치 재료 | 크리스탈 |
|---|---|---|---|
| 쉬움 | 약 68만 | 약 104만 EXP | 9,500 |
| 하드 | 약 109만 | 약 167만 EXP | 14,250 |
| 극악 | 약 170만 | 약 261만 EXP | 19,000 |

- 레벨 상한 관문: 4챕터(적 Lv.17~24) ≈ 40 돌파, 8챕터(Lv.39~46) ≈ 60 돌파, 12챕터(Lv.60~67) ≈ 80 돌파.
- 특수 던전 개방(쉬움): 돌파 던전 3-6 → 초급, 6-6 → 중급, 10-6 → 상급 · 금화/스킬 교본 던전 1-6 / 4-6 / 7-6 / 10-6 / 13-6 → 1~5단계 · 장비 던전(5곳 공통) 2-6 / 4-6 / 7-6 / 10-6 / 13-6 → 1~5단계.
- 수치는 `StageContent`의 공식에서 바꾼 뒤 메인 씬 생성기를 다시 실행하면 270개 에셋이 갱신됩니다.
  쉬움 = `Demo/Stages/Stage_c-n.asset`, 하드 = `Stages/Hard/`, 극악 = `Stages/Hell/`.

## 해금 기능

| 조건 | 해금 |
|---|---|
| 챕터 1 클리어 (1-6 보스) | 전투 **2배속** — 결과 화면에 `2배속 해금!` 표시 |
| 챕터 3 클리어 (3-6 보스) | 전투 **3배속** — `3배속 해금!`, 배속 버튼을 눌러 ×1 → ×2 → ×3 조절 |

- 자동 전투는 처음부터 사용 가능. 해금 판정: `StageRunner.SpeedUnlocked` (`SpeedUnlockChapter`로 챕터 변경).

**테스트용**: Meta 오브젝트 → Stage Progress ⋮ → `스테이지 진행도 초기화`.
