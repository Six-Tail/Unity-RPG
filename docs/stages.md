# 스테이지 · 전투 보상

홈 → **스테이지** → 스테이지 선택 → **편성 후 출격** → 파티 선택 → **출격!** → 전투 → 결과(별 평가 + 보상) → **스테이지로**

## 구성 요소

| 파일 | 역할 |
|---|---|
| [StageData.cs](../Assets/_Project/Scripts/Meta/Stages/StageData.cs) | 스테이지 1개 (SO). 적(유닛 + 레벨), 권장 레벨, ★3 행동 제한, 보상 |
| [StageDatabase.cs](../Assets/_Project/Scripts/Meta/Stages/StageDatabase.cs) | 스테이지 목록 + 챕터 이름. 진행 순서 = (챕터, 번호) |
| [StageProgress.cs](../Assets/_Project/Scripts/Meta/Stages/StageProgress.cs) | 최고 별·클리어 횟수 저장 (PlayerPrefs `stages`), 해금 판정 |
| [StageRunner.cs](../Assets/_Project/Scripts/Meta/Stages/StageRunner.cs) | 출격(적 레벨 적용) → 종료 시 별 평가·보상 지급·결과 표시 |
| [StageScreen.cs](../Assets/_Project/Scripts/Meta/UI/StageScreen.cs) | 챕터 탭 · 스테이지 노드 · 상세 패널 UI |

- 적은 같은 유닛 에셋을 **레벨만 바꿔** 재사용합니다(실행 중 복제본 사용, 원본 에셋 그대로). 데모 적은 레벨당 능력치 +7%.
- 편성 화면은 스테이지에서 들어오면 **출격 모드**(제목 `출격 준비 · 1-3 …`, 버튼 `출격!`, 뒤로 `← 스테이지`)로 바뀝니다. 홈에서 들어오면 **연습 전투**(기본 적, 보상 없음).

## 해금 · 별 평가

- 진행 순서상 **앞 스테이지를 클리어하면 다음 스테이지가 열립니다** (챕터 1-1은 항상 열림, 챕터 탭도 첫 스테이지 해금 시 열림).
- 별(최고 기록 유지):

| 별 | 조건 |
|---|---|
| ★1 | 클리어 |
| ★2 | 아군 전원 생존 |
| ★3 | 아군 행동 `turnLimit`회 이내 클리어 |

## 보상

| 종류 | 지급 |
|---|---|
| 크리스탈 | **첫 클리어 1회만** (반복 파밍으로 무한 획득 방지) |
| 금화 · 경험치 재료(챕터 1 소형 물약·물약·대형 물약, 챕터 2 대형 물약·결정) | 클리어할 때마다 (돌파 재료는 **돌파 던전**에서만 — [economy.md](economy.md)) |
| 캐릭터 경험치 | 클리어할 때마다, **출전한 캐릭터 전원** (레벨 상한이면 돌파 필요) |

- 패배: 보상 없음.
- 결과 화면 `다시`로 재도전해도 다시 평가·지급됩니다.

## 데모 스테이지 (메인 씬 생성기)

| 챕터 | 스테이지 | 적 레벨 | 첫 클리어 크리스탈 |
|---|---|---|---|
| 1 그림자 숲 | 1-1 ~ 1-5, **1-6 보스 어둠군주** | Lv.1 → 13 | 60 × 5 + 160 = **460** |
| 2 얼어붙은 성채 | 2-1 ~ 2-5, **2-6 보스 빙결거인** | Lv.15 → 27 | 80 × 5 + 240 = **640** |

- 전 스테이지 첫 클리어 합계 1,100 크리스탈 ≈ 단차 6~7회.
- 챕터 2는 레벨 상한(20)을 넘으므로 **돌파**가 필요합니다 — 1-3 클리어로 열리는 **돌파 던전 초급**에서 속성 재료를 모으세요.
- 매 클리어 금화: 챕터 1 1,200 → 2,400 (보스 4,000), 챕터 2 3,000 → 4,200 (보스 7,000).
- 돌파 던전 개방: 1-3 → 초급, 2-3 → 중급, 2-6 → 상급.
- 수치는 `MainSceneGenerator.BuildStages()`에서 조정하거나, 생성된 `Assets/_Project/Demo/Stages/Stage_*.asset`을 인스펙터에서 바로 수정.

## 해금 기능

| 조건 | 해금 |
|---|---|
| 챕터 1 클리어 (1-6 보스) | 전투 **2배속** — 결과 화면에 `2배속 해금!` 표시 |

- 자동 전투는 처음부터 사용 가능. 해금 판정: `StageRunner.SpeedUnlocked` (`SpeedUnlockChapter`로 챕터 변경).

**테스트용**: Meta 오브젝트 → Stage Progress ⋮ → `스테이지 진행도 초기화`.
