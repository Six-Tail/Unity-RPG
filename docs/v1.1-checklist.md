> 「빛」, 캐릭터 이름(`c_new…`), 세트 · 던전 · 챕터 이름은 모두 **임시**입니다. 0단계에서 확정한 뒤 아래 항목의 이름을 바꿔 쓰세요.

진행 순서: **0 → A → B · C (동시 진행 가능) → D → E → F**. A(속성)가 끝나야 B · C · D에서 빛 속성을 쓸 수 있습니다.
