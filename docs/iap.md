# 인앱 결제 (Unity IAP)

실제 돈으로 파는 상품 — **크리스탈 충전 · 패키지 · 월정액 · 시즌 패스 프리미엄**.

- 결제 처리: [IapStore.cs](../Assets/_Project/Scripts/Meta/Shop/IapStore.cs) — Unity IAP **5.5.1**(`Packages/manifest.json`, `PurchasingController` 방식, 구글 플레이 결제 라이브러리 9.x). Unity IAP 4는 2026-06-08부로 지원 종료라 5를 씀
- 상품 목록: [IapCatalog.cs](../Assets/_Project/Scripts/Meta/Shop/IapCatalog.cs)
- 패키지(어셈블리 `Unity.Purchasing`)가 설치되면 에디터가 스크립트 기호 `IAP_PRESENT`를 켭니다([IapDefine.cs](../Assets/_Project/Scripts/Editor/IapDefine.cs)) — Vivox(`VIVOX_PRESENT`)와 같은 방식.

## 플랫폼별 동작

| 환경 | 동작 |
|---|---|
| 안드로이드 · iOS | 구글 플레이 · 앱 스토어 실제 결제. 가격은 스토어가 알려 준 **현지 가격**으로 표시(못 받으면 아래 표의 원화 가격) |
| 에디터 (패키지 있음) | Unity IAP **가짜 스토어** — 돈이 나가지 않는 테스트 결제 창이 뜨고, 확인하면 지급 |
| 에디터 · 개발 빌드 (패키지 없음) | **테스트 결제** — 결제 없이 바로 지급, 상점 안내 줄에 `[테스트 결제]` 표시 |
| Windows (직접 배포) | 결제 불가 — "PC 버전에서는 결제할 수 없습니다. 모바일에서 같은 계정으로 구매하면 PC에도 반영됩니다" (클라우드 저장으로 계정 공유) |
| 출시 빌드인데 패키지 없음 | 결제 불가(준비 중) |

## 결제 흐름 · 안전 장치

1. 카드의 가격 버튼 → `IapStore.Buy` → **살 수 없는 상태면 결제 창을 띄우기 전에 막음**(한도 도달 · 월정액 180일 · 이미 프리미엄).
2. 스토어 결제 창 → 결제 완료 → `OnPurchasePending` → `IapCatalog` 의 지급 함수 → **거래 ID 기록**(같은 거래를 두 번 지급하지 않음, 최근 200개 · 저장 키 `iap.tx`) → 확정.
3. 게임이 아직 준비되지 않았을 때(지갑 등이 없음) 결제가 들어오면 **보류**해 두었다가 준비되면 지급 후 확정. 앱이 꺼져 지급 전에 끝났으면 다음 실행 때 스토어 연결 후 `FetchPurchases`로 확정 안 된 주문을 다시 받아 지급.
4. 결제가 승인 대기(가족 승인 · 현금 결제 등)면 "결제가 승인 대기 중입니다" — 승인되면 다음에 자동 지급.
5. 실패 · 취소는 상점에 이유를 띄움(`결제를 취소했습니다`, `결제가 거절되었습니다` …).

**아직 없는 것**: 영수증 **서버 검증**(위조 영수증 방어), 환불 회수. 출시 규모가 커지면 Cloud Code 등으로 검증 서버를 붙이는 것을 권장합니다.

## 스토어 등록 (직접 해야 하는 일)

**구글 플레이** (Play Console)
1. 앱 만들기 → 결제 프로필(판매자 계정) 연결.
2. **내부 테스트 트랙**에 aab를 한 번 올려야 인앱 상품을 만들 수 있음.
3. 수익 창출 → 제품 → **인앱 상품** → 위 표의 ID · 가격으로 **관리형 상품** 생성 → 활성화.
4. 설정 → **라이선스 테스트**에 테스트 계정 이메일 추가 → 그 계정으로 설치하면 실제 결제 없이 테스트 결제.

**앱 스토어** (App Store Connect, Mac 필요)
1. 계약 · 세금 · 은행 정보(유료 앱 계약) 완료.
2. 앱 → 앱 내 구입 → **소모품**으로 위 표의 ID 등록(가격 등급 선택, 심사용 스크린샷 · 설명).
3. 사용자 및 액세스 → **샌드박스 테스터** 계정으로 기기에서 테스트.

## 테스트

- **에디터**: 패키지가 설치된 뒤 상점 → `크리스탈 충전` → 가격 버튼 → 가짜 스토어 창에서 `Buy` → 지급 · 첫 구매 2배 표시가 사라짐. `Cancel`이면 "결제를 취소했습니다".
- **패키지가 없을 때**: 안내 줄에 `[테스트 결제]` → 누르면 바로 지급.
- 패키지 · 월정액 · 시즌 패스도 같은 방식. 한도에 걸리면 결제 창 없이 이유만 뜸.
