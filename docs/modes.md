## 결투장(PVP)

다른 지휘관의 팀(실제 캐릭터로 만든 AI 팀)과 겨룹니다. 상대는 AI가 조종합니다.

| 항목 | 내용 |
|---|---|
| 도전권 | 하루 5장(매일 05:00 충전). 출격할 때 쓰고, 끝나기 전에 나가면 돌려받음 |
| 랭크 점수 | 시작 1,000 · 티어 브론즈(~1099) · 실버(~1299) · 골드(~1599) · 플래티넘(~1999) · 다이아(~2499) · 마스터 |
| 상대 3명 | 쉬움 · 보통 · 어려움 — 내 주력 4명 평균 레벨 −6 / ±0 / +6, 어려움은 초월 0~2. 팀 4명 무작위, 전투력 표시 |
| 승리 | 쉬움 +12점 · 크리스탈 20 · 금화 3,000 / 보통 +20 · 30 · 5,000 / 어려움 +32 · 50 · 8,000, 이기면 상대 새로 |
| 패배 | −8점 · 금화 1,000 |
| 새로고침 | `상대 새로고침`으로 언제든 다시 뽑기 |

결투장 배경: `Backgrounds/arena`. 테스트: Player Arena 컴포넌트 ⋮ → `테스트: 도전권 가득 채우기`.

## 주간 보스(월드 레이드)

체력이 사실상 끝없는 보스 **별을 삼키는 자**에게 준 피해를 한 주 동안 쌓아 보상을 받습니다.

| 항목 | 내용 |
|---|---|
| 도전 | 하루 3회(05:00 충전). 끝나기 전에 나가면 돌려받음 |
| 한 번의 전투 | 아군 행동 20회까지 → `TIME UP` · `전투 종료`(패배 아님). 전멸해도 그때까지 준 피해는 기록 |
| 보스 | 레벨 = 내 주력 4명 평균(최소 10), 체력 99,999,999, 내구도 420, **약점 2속성이 매주 바뀜**(화염·얼음 → 번개·바람 → 물리·화염 → 얼음·번개 → 바람·물리) |
| 기록 | 이번 주 누적 피해 · 1회 최고 기록 |
| 초기화 | 매주 월요일 05:00(누적 · 수령 기록) |

누적 피해 보상(수동 수령):

| 누적 피해 | 보상 |
|---|---|
| 50,000 | 금화 20,000 |
| 150,000 | 대형 경험치 물약 ×5 |
| 400,000 | 크리스탈 100 |
| 1,000,000 | 상급 스킬 교본 ×3 |
| 2,500,000 | 크리스탈 200 · 행동력 물약 ×2 |
| 6,000,000 | 전설의 비전서 ×1 |
| 15,000,000 | 픽업 뽑기권 ×1 · 크리스탈 300 |

받을 보상이 있으면 홈 타일에 `●N`. 테스트: World Raid 컴포넌트 ⋮ → `테스트: 도전 횟수 초기화`.

## 구현 메모

- 전투 강제 종료: `BattleController.RequestEnd(winner)` — 지금 행동이 끝난 뒤 종료 처리. 결과 문구는 `BattleHUD.SetEndTexts(마무리, 제목, 색)`(다음 한 번만).
- 편성 → 전투 → 나가기 경로: `ScreenNavigator.OpenModeParty` (나가면 결투장 / 주간 보스 화면으로).
- 이미지(스튜디오 생성): `Backgrounds/arena` · `Backgrounds/raid` · `Enemies/별을 삼키는 자` · 아이콘 `Items/ArenaCoin` · `Items/RaidIcon`.
