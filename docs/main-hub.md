# 메인 씬 (홈 허브)

위치: `Assets/_Project/Scenes/Main.unity` — 생성: 메뉴 **`SubcultureRPG > 메인 씬 생성 (홈 허브)`**

스테이지·가챠·육성·편성·가방·전투를 **한 씬**에 모아, 홈 화면에서 버튼으로 오가는 실제 게임 진입점입니다. 빌드 설정의 **첫 씬**으로 등록됩니다.

## 화면 흐름

```
              ┌────────── 홈 ──────────┐
              │ 크리스탈·금화            │
              │ 대표 캐릭터(누르면 대사)  │
              └──┬──────┬──────┬──────┬──────┬──────┬┘
                 │      │      │      │      │      │
            스테이지   가챠   육성   임무   상점   가방
                 │
            (위쪽 탭: 쉬움 · 하드 · 극악 · 특수 던전)
                 │
       (편성 후 출격) ──▶ 편성[출격 모드] ──(출격!)──▶ 전투 ──▶ 결과(별·보상) ──▶ 스테이지로
```

- **스테이지**: 챕터·스테이지 선택 → 출격 모드 편성 → 전투 → 별 평가·보상 → 스테이지 목록. 자세히: [stages.md](stages.md)
- **가챠**: 크리스탈로 뽑기 → 결과 연출 → 로스터 자동 보유. 결과 화면의 재뽑기도 **크리스탈 차감**(부족하면 결과 화면을 닫고 안내).
- **육성**: 재료로 레벨업·돌파·스킬 레벨업.
- **특수 던전**: 홈 메뉴에는 없고 스테이지 화면 위쪽 `특수 던전` 탭(돌파 · 금화 · 스킬 교본 · 경험치 · 장비 던전)에서 들어갑니다. 탭 이름은 개방 여부와 관계없이 `특수 던전`. 편성은 출격할 때만 열립니다(연습 전투 메뉴 삭제).
- **전투 종료**: 결과 화면에서 `다시`(같은 편성 재도전) 또는 `홈으로`/`스테이지로`. 스테이지 승리 시 `다음 스테이지로`(5초 후 자동 진행)도 표시. 전투 중 좌상단 `← 나가기`로 중단.
- **임무**: `일일 임무 · 주간 임무`를 달성하고 보상(크리스탈 · 금화 · 재료 · **뽑기권**)을 받습니다. 홈 버튼에 받을 보상 수 표시. 자세히: [missions.md](missions.md)
- **도감**: 홈 오른쪽 메뉴 `도감` 타일. 전체 캐릭터(미보유는 어둡게) · 일러스트 크게 보기 · 수집 보상. 자세히: [codex.md](codex.md)
- **상점**: `일반 상점(금화 · 매일) · 크리스탈 상점(매주) · 교환소`. 수량 선택 후 구매, 크리스탈 결제는 확인 창. 자세히: [shop.md](shop.md)
- **가방**: 위쪽 탭 `전체 · 경험치 재료 · 스킬 재료 · 돌파 재료 · 장비 재료`로 분류. 칸 테두리 = 등급 색(고급 초록 · 희귀 파랑 · 영웅 보라 · 전설 금색), 많으면 스크롤. 재료를 누르면 등급·용도·획득처.
- **편성(출격 준비)**: 선택한 캐릭터는 두꺼운 하늘색 테두리 + 덮개 + `출전 N` 리본(출전 순서)으로 표시, 살짝 커짐. 4명이 차면 나머지는 흐려지고 아래에 출전 캐릭터 이름이 나옵니다.

## 구성

| 파일 | 역할 |
|---|---|
| `ScreenNavigator` (Meta) | 화면 전환. 한 번에 한 화면만 표시, 홈 버튼/편성→전투/나가기 연결 |
| `HomeScreen` (Meta.UI) | 홈(로비) — 대표 캐릭터(왼쪽, 누르면 대사), 크리스탈·금화(우상단), 스테이지 · 가챠 · 육성 · 임무 · 상점 · 가방 · 도감 · 대표 변경 |
| `BagScreen` (Meta.UI) | 가방 — 재화 + 분류 탭 · 등급 색 재료 목록, 선택 재료의 등급·용도·획득처 |
| `StageScreen` · `StageRunner` · `StageProgress` | 스테이지 선택 · 스테이지 전투 진행/보상 · 진행도 저장 |
| `PartyScreen.SetLaunchMode` | 편성 화면 출격 모드(스테이지·던전) |
| 각 화면의 `Show(bool)` · `SetBackAction` | 허브에서 표시 제어와 '← 홈' 버튼 연결(허브가 아닐 땐 홈 버튼 숨김) |
| `PartyScreen.OnLaunched` | 전투 시작 시 이벤트 → 내비게이터가 전투 화면으로 전환 |
| `BattleHUD.SetExitAction` · `SetExitLabel` · `SetResultDetail` | 전투 '나가기' 버튼, 결과 버튼 문구, 결과 화면 별·보상 표시 |
| `GachaResultPanel.SetPullHandler` | 결과 화면 재뽑기를 `GachaScreen`에 위임(비용 차감) |
| `PlayerRoster.starterCharacters` | 새 세이브(보유 0명)일 때 지급할 스타터 |

## 데이터

- 캐릭터·배너·적 에셋은 `Assets/_Project/Demo/`의 것을 사용합니다.
- **`MainDatabase.asset`** 에 배너 풀의 **25종 전부**(픽업 6★ 2 · 상시 6★ 5 · 5★/4★/3★ 각 6)를 등록 → 무엇을 뽑아도 육성·편성에 표시됩니다.
- 스타터: 리리·미나·코코 (새 세이브에서만).
- 세이브(`PlayerPrefs`)는 데모 씬들과 **공유**합니다(같은 플레이어). 처음부터 해보려면 `Meta` 오브젝트의 컴포넌트 우클릭 → `로스터 초기화` / `지갑 초기화`.

## 참고

- 개별 데모 씬(전투/가챠/연동/육성)은 그대로 동작합니다. 허브용 버튼은 내비게이터가 연결할 때만 보입니다.
- 6성 Live2D: SDK와 모델 폴더를 넣으면 홈 대표 캐릭터 · 도감 · 가챠 6성 연출에 나옵니다(홈은 대표 캐릭터로 고른 경우) — [live2d.md](live2d.md)
- 확장: 이벤트.

## 홈 화면(로비)

- **대표 캐릭터**: 보유 캐릭터 중 하나가 왼쪽에 크게 서 있습니다(움직이는 일러스트가 있으면 그것). 누르면 톡 튀며 **그 캐릭터의 로비 대사** 중 하나가 말풍선으로 3초 뜹니다(바로 전 대사는 피해서 무작위). 대사: [CharacterLines.cs](../Assets/_Project/Scripts/Characters/CharacterLines.cs) — 캐릭터마다 5개(외형·무기·성격·1장 스토리에 맞춤), 6★은 대표 대사도 후보에 포함. 전용 대사가 없는 새 캐릭터는 역할별 기본 대사. 왼쪽 아래에 성급·초월 별, 이름, 속성·역할.
- **대표 변경**: 프로필 창 `로비 설정` → 보유 캐릭터 목록(성급 높은 순, 스크롤)에서 고르면 바로 바뀜. `PlayerPrefs` `home.assistant`에 기억, 고른 적이 없거나 그 캐릭터가 없으면 보유 중 가장 높은 성급.
- **메뉴**(오른쪽): `스테이지`(가장 크게) · `가챠` · 2열 타일 `육성 · 임무 · 결투장 · 주간 보스`([modes.md](modes.md)). 임무 · 주간 보스 타일에 받을 보상 수(●N), 결투장 타일에 티어 · 도전권.
- **상점 · 가방**: 오른쪽 위 재화 알약 왼쪽의 아이콘 버튼.
- **도감 · 대표 변경**: 프로필 창(왼쪽 위 배지)의 `도감` · `로비 설정`. 도감 수집 보상이 있으면 프로필 배지에 빨간 점.
- **재화**(오른쪽 위): 크리스탈 · 금화 알약(아래 "재화 표시" 참고). 픽업 배너 정보는 가챠 화면에서만 보여 줍니다.

## 재화 표시(모든 화면 공용)

오른쪽 위 재화는 모든 화면이 같은 모양을 씁니다 — [CurrencyBar.cs](../Assets/_Project/Scripts/Meta/UI/CurrencyBar.cs): 어두운 알약 + 아이콘 + 숫자, 지갑이 바뀌면 스스로 갱신.

| 화면 | 1줄 | 2줄 |
|---|---|---|
| 홈 · 가방 · 상점 | 크리스탈 · 금화 | — |
| 임무 | 크리스탈 · 금화 | 픽업 · 상시 뽑기권 |
| 가챠 | 지금 배너의 뽑기권(픽업 뽑기 = 픽업 뽑기권, 상시 뽑기 = 상시 뽑기권) · 크리스탈 | — |
| 육성 | 금화 | — |
| 스테이지 | 행동력(알약 아래 `+1까지 m:ss`) · 왼쪽에 테스트 충전 버튼 | 별 합계 |

아이콘: `Resources/Art/Items/{Crystal · Gold · PickupTicket · StandardTicket · Stamina}.png` (없으면 색 점).

`PlayerWallet`은 값을 처음 읽힐 때 세이브를 불러오고, 불러오기 전에는 저장하지 않습니다(다른 화면이 시작 중에 먼저 읽어도 세이브가 기본값으로 덮이지 않게).

## 타이틀 화면 (게임 시작)

[TitleScreen.cs](../Assets/_Project/Scripts/Meta/UI/TitleScreen.cs) — 메인 씬이 뜨면 자동으로 만들어져 모든 화면 위에 표시됩니다(씬에 따로 넣을 필요 없음).

1. **로고**: 검은 화면에 엠블럼(닻 + 별)과 게임 이름 `스텔라 앵커 / STELLAR ANCHOR`가 떠오름(약 2초, 누르면 바로 다음).
2. **로딩**: 픽업 캐릭터 키 아트(세라핀 · 시엘)가 나타나고 로고는 아래 가운데로 작아짐. 자주 쓰는 그림(배경 · 캐릭터 일러스트/썸네일 · 아이콘 · 가챠 소품)을 비동기로 미리 불러오며 진행 막대 · 퍼센트 · 도움말 표시.
3. **TAP TO START**: 로딩이 끝나면 그림이 밝아지고 안내가 깜빡임. 화면을 눌러야 홈으로 넘어감.

- 게임 이름 · 한 줄 소개 · 도움말은 `TitleScreen`의 상수(`GameName` · `GameNameEn` · `Tagline` · `Tips`)에서 바꿉니다. 홈 화면 왼쪽 위의 게임 이름은 없앴습니다.
- 그림: `Resources/Art/Title/logo.png`(엠블럼만 — 글자는 게임 폰트로 그림) · `Title/keyart.jpg`. 다시 만들기: `node tools/art/generate-art.js --only title` (키 아트는 `tools/art/refs/pickup_pair.png`를 참고 이미지로 써서 기존 일러스트와 같은 캐릭터로 그림). 픽업 캐릭터가 바뀌면 참고 이미지와 프롬프트를 바꿔 다시 생성.

홈 왼쪽 위에는 **프로필 배지**(아바타 · 칭호 · 이름 · 레벨)가 있고, 누르면 프로필 창이 열립니다 → [profile.md](profile.md).
