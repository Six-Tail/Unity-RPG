# 메인 씬 (홈 허브)

위치: `Assets/_Project/Scenes/Main.unity` — 생성: 메뉴 **`SubcultureRPG > 메인 씬 생성 (홈 허브)`**

스테이지·가챠·육성·편성·가방·전투를 **한 씬**에 모아, 홈 화면에서 버튼으로 오가는 실제 게임 진입점입니다. 빌드 설정의 **첫 씬**으로 등록됩니다.

## 화면 흐름

```
              ┌────────── 홈 ──────────┐
              │ 크리스탈·금화·보유 수     │
              │ 픽업 캐릭터              │
              └──┬──────┬──────┬──────┬──────┬──────┬┘
                 │      │      │      │      │      │
            스테이지   가챠   육성   임무   상점   가방
                 │
            (위쪽 탭: 쉬움 · 하드 · 극악 · 특수 던전)
                 │
       (편성 후 출격) ──▶ 편성[출격 모드] ──(출격!)──▶ 전투 ──▶ 결과(별·보상) ──▶ 스테이지로
```

- **스테이지**: 챕터·스테이지 선택 → 출격 모드 편성 → 전투 → 별 평가·보상 → 스테이지 목록. 자세히: [stages.md](stages.md)
- **가챠**: 크리스탈로 뽑기 → 결과 연출 → 로스터 자동 보유. 결과 화면의 재뽑기도 **크리스탈 차감**(부족하면 결과 화면을 닫고 안내).
- **육성**: 재료로 레벨업·돌파·스킬 레벨업.
- **특수 던전**: 홈 메뉴에는 없고 스테이지 화면 위쪽 `특수 던전` 탭(돌파 · 금화 · 스킬 교본 · 경험치 · 장비 던전)에서 들어갑니다. 탭 이름은 개방 여부와 관계없이 `특수 던전`. 편성은 출격할 때만 열립니다(연습 전투 메뉴 삭제).
- **전투 종료**: 결과 화면에서 `다시`(같은 편성 재도전) 또는 `홈으로`/`스테이지로`. 스테이지 승리 시 `다음 스테이지로`(5초 후 자동 진행)도 표시. 전투 중 좌상단 `← 나가기`로 중단.
- **임무**: `일일 임무 · 주간 임무`를 달성하고 보상(크리스탈 · 금화 · 재료 · **뽑기권**)을 받습니다. 홈 버튼에 받을 보상 수 표시. 자세히: [missions.md](missions.md)
- **상점**: `일반 상점(금화 · 매일) · 크리스탈 상점(매주) · 교환소`. 수량 선택 후 구매, 크리스탈 결제는 확인 창. 자세히: [shop.md](shop.md)
- **가방**: 위쪽 탭 `전체 · 경험치 재료 · 스킬 재료 · 돌파 재료 · 장비 재료`로 분류. 칸 테두리 = 등급 색(고급 초록 · 희귀 파랑 · 영웅 보라 · 전설 금색), 많으면 스크롤. 재료를 누르면 등급·용도·획득처.
- **편성(출격 준비)**: 선택한 캐릭터는 두꺼운 하늘색 테두리 + 덮개 + `출전 N` 리본(출전 순서)으로 표시, 살짝 커짐. 4명이 차면 나머지는 흐려지고 아래에 출전 캐릭터 이름이 나옵니다.

## 구성

| 파일 | 역할 |
|---|---|
| `ScreenNavigator` (Meta) | 화면 전환. 한 번에 한 화면만 표시, 홈 버튼/편성→전투/나가기 연결 |
| `HomeScreen` (Meta.UI) | 홈 — 크리스탈·금화(우상단), 픽업 캐릭터, 스테이지/가챠/육성/편성/가방 버튼, 보유 수 |
| `BagScreen` (Meta.UI) | 가방 — 재화 + 분류 탭 · 등급 색 재료 목록, 선택 재료의 등급·용도·획득처 |
| `StageScreen` · `StageRunner` · `StageProgress` | 스테이지 선택 · 스테이지 전투 진행/보상 · 진행도 저장 |
| `PartyScreen.SetLaunchMode` | 편성 화면 출격 모드(스테이지·던전) |
| 각 화면의 `Show(bool)` · `SetBackAction` | 허브에서 표시 제어와 '← 홈' 버튼 연결(허브가 아닐 땐 홈 버튼 숨김) |
| `PartyScreen.OnLaunched` | 전투 시작 시 이벤트 → 내비게이터가 전투 화면으로 전환 |
| `BattleHUD.SetExitAction` · `SetExitLabel` · `SetResultDetail` | 전투 '나가기' 버튼, 결과 버튼 문구, 결과 화면 별·보상 표시 |
| `GachaResultPanel.SetPullHandler` | 결과 화면 재뽑기를 `GachaScreen`에 위임(비용 차감) |
| `PlayerRoster.starterCharacters` | 새 세이브(보유 0명)일 때 지급할 스타터 |

## 데이터

- 캐릭터·배너·적 에셋은 `Assets/_Project/Demo/`의 것을 사용합니다.
- **`MainDatabase.asset`** 에 배너 풀의 **25종 전부**(픽업 6★ 2 · 상시 6★ 5 · 5★/4★/3★ 각 6)를 등록 → 무엇을 뽑아도 육성·편성에 표시됩니다.
- 스타터: 리리·미나·코코 (새 세이브에서만).
- 세이브(`PlayerPrefs`)는 데모 씬들과 **공유**합니다(같은 플레이어). 처음부터 해보려면 `Meta` 오브젝트의 컴포넌트 우클릭 → `로스터 초기화` / `지갑 초기화`.

## 참고

- 개별 데모 씬(전투/가챠/연동/육성)은 그대로 동작합니다. 허브용 버튼은 내비게이터가 연결할 때만 보입니다.
- 확장: 이벤트, 6성 Live2D 등장 연출.
