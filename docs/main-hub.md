# 메인 씬 (홈 허브)

위치: `Assets/_Project/Scenes/Main.unity` — 생성: 메뉴 **`SubcultureRPG > 메인 씬 생성 (홈 허브)`**

스테이지·가챠·육성·편성·가방·전투를 **한 씬**에 모아, 홈 화면에서 버튼으로 오가는 실제 게임 진입점입니다. 빌드 설정의 **첫 씬**으로 등록됩니다.

## 화면 흐름

```
              ┌────────── 홈 ──────────┐
              │ 크리스탈·금화            │
              │ 대표 캐릭터(누르면 대사)  │
              └──┬──────┬──────┬──────┬──────┬──────┬┘
                 │      │      │      │      │      │
            스테이지   가챠   육성   임무   상점   가방
                 │
            (맨 위 탭: 메인 스토리 / 특수 던전)
                 │
       (편성 후 출격) ──▶ 편성[출격 모드] ──(출격!)──▶ 전투 ──▶ 결과(별·보상) ──▶ 스테이지로
```

- **스테이지**: 챕터·스테이지 선택 → 출격 모드 편성 → 전투 → 별 평가·보상 → 스테이지 목록. 자세히: [stages.md](stages.md)
- **가챠**: 크리스탈로 뽑기 → 결과 연출 → 로스터 자동 보유. 결과 화면의 재뽑기도 **크리스탈 차감**(부족하면 결과 화면을 닫고 안내).
- **육성**: 재료로 레벨업·돌파·스킬 레벨업.
- **특수 던전**: 스테이지 화면 맨 위 `메인 스토리 / 특수 던전` 탭으로 나뉩니다. 특수 던전은 종류 탭(장비 · 돌파 · 경험치 · 금화 · 스킬 교본) + 왼쪽 단계 목록(1~10단계) + 가운데 그림 · 보상 · 적, 장비 던전은 지도에서 장소를 먼저 고릅니다([stages.md](stages.md#특수-던전-화면)). 편성은 출격할 때만 열립니다(연습 전투 메뉴 삭제).
- **편성 화면**: 선택한 순서가 출전 순서. 아래 왼쪽 **편성 프리셋 1 ~ 5**(누르면 불러오기, `저장`으로 지금 파티를 원하는 칸에 저장), 아래 오른쪽 **`장비 자동 장착`**(선택한 파티 — [equipment.md](equipment.md#자동-장착)). 직전에 출격한 파티를 기억해 편성 화면을 열면 미리 골라 둡니다. 코드: [PartyPresets.cs](../Assets/_Project/Scripts/Meta/PartyPresets.cs) · [PartyScreen.cs](../Assets/_Project/Scripts/Meta/UI/PartyScreen.cs).
- **전투 종료**: 결과 화면에서 `다시`(같은 편성 재도전) 또는 `홈으로`/`스테이지로`. 스테이지 승리 시 `다음 스테이지로`(5초 후 자동 진행)도 표시. 전투 중 좌상단 `← 나가기`로 중단.
- **임무**: `일일 임무 · 주간 임무`를 달성하고 보상(크리스탈 · 금화 · 재료 · **뽑기권**)을 받습니다. 받을 보상이 있으면 아래 메뉴 바 `임무`에 빨간 느낌표. 자세히: [missions.md](missions.md)
- **도감**: 홈 위쪽 `메뉴` → `도감`. 전체 캐릭터(미보유는 어둡게) · 일러스트 크게 보기 · 수집 보상. 자세히: [codex.md](codex.md)
- **상점**: `일반 상점(금화 · 매일) · 크리스탈 상점(매주) · 교환소`. 수량 선택 후 구매, 크리스탈 결제는 확인 창. 자세히: [shop.md](shop.md)
- **가방**(2026-11 개편): 왼쪽 세로 탭 `전체 · 경험치 재료 · 스킬 재료 · 돌파 재료 · 장비 재료 · 기타`(대표 아이콘 · `보유 n/m종`) + `보유한 것만` 켬/끔. 가운데 5열 둥근 칸 — 테두리와 아이콘 뒤 빛 = 등급 색(고급 초록 · 희귀 파랑 · 영웅 보라 · 전설 금색), 없는 것은 흐리게, 아래 띠에 이름(경험치 양 · 돌파 속성). 칸을 누르면 목록은 그대로 두고 오른쪽 상세만 바뀜: 큰 아이콘 · 이름 · 등급 | 분류 · 보유 수 · 용도 · 획득처(길면 스크롤) · `사용`(행동력 물약 · 캐릭터 선택권).
  - **바로 가기**: 상세 아래에 획득처 · 사용처 버튼(최대 6개, `사용` 버튼이 있으면 3개). 경험치 → 경험치 던전 · 메인 스토리, 교본 → 스킬 교본 던전, 돌파 재료 → 돌파 던전(그 속성 탭), 장비 강화석 → 장비 던전, 재련석 → 무한의 탑 · 주간 보스, 소탕권 → 임무, 별의 조각 → 소환, 길드 코인 → 길드. 상점은 카탈로그를 읽어 그 재료를 파는 탭(일반 · 크리스탈 · 교환소 · 길드 상점 — 열면 그 상품이 선택됨)과 그 재료로 값을 치르는 탭(`(사용)`)을 자동으로 붙임. 잠긴 콘텐츠는 평소처럼 '아직 열리지 않았습니다' 안내. 이동한 화면의 뒤로 가기는 홈.
- **편성(출격 준비)**: 선택한 캐릭터는 두꺼운 하늘색 테두리 + 덮개 + `출전 N` 리본(출전 순서)으로 표시, 살짝 커짐. 4명이 차면 나머지는 흐려지고 아래에 출전 캐릭터 이름이 나옵니다.

## 홈 화면(로비)

- **대표 캐릭터**: 보유 캐릭터 중 하나가 왼쪽에 크게 서 있습니다(움직이는 일러스트가 있으면 그것). 누르면 톡 튀며 **그 캐릭터의 로비 대사** 중 하나가 말풍선으로 3초 뜹니다(바로 전 대사는 피해서 무작위). 대사: [CharacterLines.cs](../Assets/_Project/Scripts/Characters/CharacterLines.cs) — 캐릭터마다 5개(외형·무기·성격·1장 스토리에 맞춤), 6★은 대표 대사도 후보에 포함. 전용 대사가 없는 새 캐릭터는 역할별 기본 대사. 왼쪽 아래에 성급·초월 별, 이름, 속성·역할.
- **대표 변경**: 프로필 창 `로비 설정` → 보유 캐릭터 목록(성급 높은 순, 스크롤)에서 고르면 바로 바뀜. `PlayerPrefs` `home.assistant`에 기억, 고른 적이 없거나 그 캐릭터가 없으면 보유 중 가장 높은 성급.
- **배치(2026-11 개편)** — 버튼을 역할별로 묶어 홈을 단순하게:

```
 [프로필]                              [출석][우편][메뉴] [크리스탈][금화]
                                        ┌──────────────────────┐
                                        │  출격(크게, 그림)     │ ← 스토리 · 결투장 · 레이드 · 탑 · 파견 · 이벤트
   대표 캐릭터                          └──────────────────────┘
                                        ┌──────────────────────┐
 [채팅 한 줄]                           │  소환 (픽업 캐릭터)   │
 [기간 한정 이벤트]                     └──────────────────────┘
 [이름표]        [캐릭터][편성][임무][길드][친구][상점][가방]   ← 아래 메뉴 바
```

- **출격**(오른쪽 큰 버튼): 누르면 홈 안에서 **출격 화면**이 열립니다 — 카드 6장 `스토리 · 스테이지 · 결투장 · 레이드(주간 · 월드) · 무한의 탑 · 파견 · 기간 한정 이벤트`. 카드마다 배경 그림 · 한 줄 설명 · 지금 상태(클리어 장 · 티어/순위/도전권 · 남은 횟수 · 최고 층 · 파견 진행/완료 · 이벤트 남은 기간). 잠긴 콘텐츠는 어둡게 덮고 여는 조건(눌러도 안내 창). `← 홈`/뒤로 키로 닫힘. 콘텐츠에서 홈으로 돌아오면 출격 화면이 그대로 열려 있어 다음 콘텐츠로 바로 이동(튜토리얼 중에는 닫힘). 출격 버튼에는 `스토리 N장 클리어 · 받을 보상 N곳` 요약 + 카드 중 하나라도 받을 것이 있으면 빨간 느낌표.
- **소환**: 배너를 넘겨 봅니다 — 픽업(지금은 세라핀 · 시엘) → 상시 순서. 좌우로 밀거나 `<` `>` 버튼, 가만히 두면 7초마다 다음 배너(위에 점 표시). 누르면 **지금 보이는 배너**의 뽑기 화면으로 바로 이동.
- **아래 메뉴 바**: `캐릭터(육성) · 편성 · 임무 · 길드 · 친구 · 상점 · 가방`. 임무 · 길드 · 친구에 빨간 느낌표. `편성`은 출격 없이 파티만 짜서 `편성 저장`(다음 출격 편성 화면에 미리 골라짐 — 프리셋 칸도 그대로 사용).
- **위쪽 아이콘**: `출석 · 우편`(받을 것이 있으면 느낌표, [rewards.md](rewards.md)) · `메뉴` → `시즌 패스 · 도감 · 프로필 · 로비 설정 · 설정`(패스 · 도감 보상이 있으면 메뉴에 느낌표).
- **빨간 느낌표**: 받지 않은 보상 · 오늘 할 일이 있는 곳에 표시, 받으면 사라짐. 묶음(출격 · 메뉴)은 안쪽 중 하나라도 있으면 켜짐.
- **잠금**: 결투장 · 레이드 · 파견 · 탑 · 이벤트 카드는 개방 장을 클리어하기 전까지 잠김([tutorial.md](tutorial.md)).
- **도감 · 대표 변경**: `메뉴`의 `도감` · `프로필 · 로비 설정`(왼쪽 위 프로필 배지를 눌러도 됨). 도감 수집 보상이 있으면 프로필 배지에도 빨간 점.
- 아이콘: `Resources/Art/Items/UiCharacter · UiParty · UiMission · UiMenu · UiCodex · UiSortie · UiSummon`(tools/art/art-manifest.js).
- **재화**(오른쪽 위): 크리스탈 · 금화 알약(아래 "재화 표시" 참고). 픽업 배너 정보는 가챠 화면에서만 보여 줍니다.

## 타이틀 화면 (게임 시작)

[TitleScreen.cs](../Assets/_Project/Scripts/Meta/UI/TitleScreen.cs) — 메인 씬이 뜨면 자동으로 만들어져 모든 화면 위에 표시됩니다(씬에 따로 넣을 필요 없음).

1. **로고**: 검은 화면에 엠블럼(닻 + 별)과 게임 이름 `스텔라 앵커 / STELLAR ANCHOR`가 떠오름(약 2초, 누르면 바로 다음).
2. **로딩**: 픽업 캐릭터 키 아트(세라핀 · 시엘)가 나타나고 로고는 아래 가운데로 작아짐. 자주 쓰는 그림(배경 · 캐릭터 일러스트/썸네일 · 아이콘 · 가챠 소품)을 비동기로 미리 불러오며 진행 막대 · 퍼센트 · 도움말 표시.
3. **TAP TO START**: 로딩이 끝나면 그림이 밝아지고 안내가 깜빡임. 화면을 눌러야 홈으로 넘어감.
