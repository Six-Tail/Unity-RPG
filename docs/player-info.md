# 공개 프로필 · 지휘관 정보창 · 실제 플레이어 순위

다른 플레이어(친구들)와 가상 지휘관을 **같은 순위표 · 같은 정보창**으로 보여 줍니다.

- 데이터: [PublicProfile.cs](../Assets/_Project/Scripts/Meta/Cloud/PublicProfile.cs) (`ProfileSnap` · `CharSnap` · `SnapStats`)
- 화면: [PlayerInfoWindow.cs](../Assets/_Project/Scripts/Meta/UI/PlayerInfoWindow.cs) (`PlayerInfoWindow` · `CharInfoWindow`)

## 내 공개 프로필 (서버에 올림)

로그인 중이면 **2분마다**(바뀌었을 때만) + **결투장 전투 직후** Cloud Save 공개 데이터로 올립니다.

| 키 | 내용 |
|---|---|
| `pp` | 이름 · 칭호 · 테두리 · 대표 캐릭터 · 인사말 · 레벨 · UID · 결투장 점수 · **전투력 상위 5명**(레벨 · 돌파 · 성급 · 초월 · 스킬 · 호감도 · 장착 장비 6부위) — JSON |
| `ar_season` · `ar_pts` | 결투장 시즌(주) 키 · 결투장 점수 — 순위 검색용 |
| `uid` | 내 UID(문자열) — 친구 찾기 UID 검색용 |
| `fr_to0` · `fr_to1` · `fr_to2` · `fr_list` · `fr_dec` | 친구 신청 칸(상대 플레이어 id) · 친구 id 목록 · 거절 목록 — [social.md](social.md) |

능력치 · 전투력은 올리지 않고 **볼 때 계산**합니다(내 캐릭터와 같은 계산: 레벨 · 성급 · 초월 · 스킬 · 장비 · 호감도 → `CombatPower`).

## 결투장 시즌 랭킹 = 가상 지휘관 99명 + 실제 플레이어 + 나

- 이번 시즌에 결투장 기록이 있는 실제 플레이어를 서버에서 검색(`ar_season` = 이번 주)해 가상 지휘관과 **점수 순으로 섞음**. 이름 옆 `● 플레이어` 표시
- 1번 플레이어가 싸우면 점수가 올라가고, 2번 플레이어가 랭킹을 열면 그 점수 · 티어 · 순위가 그대로 보임(결투장 화면을 열 때 1분마다 · 그 밖에 2분마다 새로 불러옴)
- 시즌 정산(월요일 05:00)도 실제 플레이어를 포함한 순위로 계산(그 시즌에 마지막으로 본 점수 — 세이브 `pubprof`)
- 랭킹 창 오른쪽 위에 `서버 플레이어 N명 + 다른 지휘관`(게스트면 안내, 인덱스가 없으면 오류 문구)

월드 레이드 순위는 서버 공유 체력과 보상이 걸려 있어 **실제 플레이어만** 보여 줍니다(가상 지휘관 섞지 않음).

## 지휘관 정보창 (모든 순위표 · 친구 · 길드원에서 누르면)

- 아바타 · 테두리 · 이름 · 칭호 · 레벨 · UID(`복사` 버튼 — 내 프로필 창에도) · 인사말 · 순위 줄(결투장 순위 · 티어 · 점수 / 월드 레이드 순위 · 피해) · 전투력(상위 5명 합)
- **전투력 상위 5명** 카드: 성급 · 초월 · 이름 · 속성 · 역할 · 레벨 · 전투력 · 장비 수 → **누르면 캐릭터 상세**
- 캐릭터 상세: 그림 · 성급 · 레벨 / 상한 · 돌파 · 초월 · 호감도 · 전투력 · 능력치(체력 · 공격 · 방어 · 속도 · 치명 · 속성 피해 · 관통 · 브레이크 · 에너지 · 치유 · 효과 명중/저항) · 스킬 3개(레벨 + 초월 보너스) · 장비 6부위(세트 · 성급 · 강화 · 장비 초월 · 주옵션 · 보조 옵션) · 세트 효과
- 가상 지휘관은 번호(seed)로 늘 같은 상위 5명 · 장비를 만들어 냄(지휘관 레벨이 높을수록 높은 성급 · 레벨 · 장비). 친구 추가는 가상 지휘관만(실제 플레이어 친구는 다음 단계)
- 월드 레이드 순위의 실제 플레이어는 누를 때 그 사람의 `pp`를 서버에서 읽음(1분 캐시)

## ⚠ 대시보드 설정 — 인덱스 1개 추가

Unity Cloud → Cloud Save → **인덱스 설정**: **플레이어 데이터 · 공개(Public)** · 필드 **`ar_season`** (월드 레이드의 `wr_week` · `wr_pweek`와 같은 방식).
없으면 결투장 랭킹에 가상 지휘관만 나오고, 랭킹 창에 "서버 검색 설정(인덱스 ar_season)이 없습니다"가 뜹니다.

**친구 신청용 인덱스 `fr_to0` · `fr_to1` · `fr_to2`**(3개, 같은 방식 — 플레이어 · 공개 · 문자열)도 필요. 없으면 `받은 신청`에 "서버 검색 설정(인덱스 fr_to0 · fr_to1 · fr_to2)이 없어..."가 뜸.

**친구 찾기용 인덱스 `uid`**도 같은 방식(플레이어 데이터 · 공개 · 필드 `uid`)으로 추가. 없으면 UID 검색이 가상 지휘관만 찾고 "서버 검색 설정(인덱스 uid)이 없어..."가 뜹니다. 찾을 상대가 이 버전으로 한 번 접속해야(공개 프로필에 `uid`가 올라감) 검색됩니다.
