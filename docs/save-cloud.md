# 세이브 · 클라우드(Unity Gaming Services)

친구들과 함께 플레이하기 위해 플레이어 데이터를 서버(UGS)에 두는 작업입니다.

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 모든 세이브를 공용 저장소 `SaveStore` 하나로 모음 | 완료 |
| 2 | 계정 로그인(아이디 · 비밀번호) + 클라우드 저장, 지금 PC 세이브 옮기기 | 완료(테스트 전) |
| 3 | 가짜 소셜을 실제 플레이어로: 친구 → 랭킹(결투장 · 주간 보스) → 결투장 상대 → 길드 | 다음 |

UGS 설정(완료): 프로젝트 연결 `subculture-rpg` · Identity Provider **Username & Password** · 패키지 Authentication 3.9.0 · Cloud Save 3.4.2.

## SaveStore ([Core/SaveStore.cs](../Assets/_Project/Scripts/Core/SaveStore.cs))

- PlayerPrefs와 같은 함수 이름(`GetString` · `SetInt` · `HasKey` · `DeleteKey` · `Save` …). 게임 코드는 PlayerPrefs를 직접 쓰지 않습니다(편집기 초기화 메뉴만 예외).
- **계정 데이터**(서버에 올림): 캐릭터 · 재화 · 장비 · 진행도 · 스토리/튜토리얼 기록 등. 쓴 키는 목록(`__savestore.keys`)에 기록. 옛 세이브의 키도 읽을 때 자동으로 목록에 들어가고, 스토리 · 튜토리얼 기록은 로그인 때 한꺼번에 넣음.
- **기기 설정**(서버에 안 올림): `sound.*` · `battle.auto` · `battle.speed` · `stage.multiplier` · `stage.repeat` · `wallet.restore.v1` · `__savestore.*`.
- `Export()` / `Import()` / `ReloadGame()` / `Changed` / `Owner`(이 PC 세이브의 계정 id).

## 계정 · 클라우드 저장 ([Meta/Cloud](../Assets/_Project/Scripts/Meta/Cloud))

**흐름**(타이틀 `TAP TO START` 다음, [CloudLogin.cs](../Assets/_Project/Scripts/Meta/Cloud/CloudLogin.cs)):

1. 서버 연결 → 실패하면 `다시 시도` / `게스트로`
2. 이 PC에 로그인 정보가 남아 있으면 자동 로그인, 없으면 **시작 선택**: 첫 줄 `로그인` · `회원가입`, 둘째 줄 `게스트로`(서버 없이 이 PC에만 저장 — 확인 창 한 번)
   - `로그인` → 로그인 창(아이디 · 비밀번호, `로그인` · `뒤로`)
   - `회원가입` → 회원가입 창(아이디 · 비밀번호 · 비밀번호 확인, `가입하기` · `뒤로`) → 가입이 끝나면 **아이디를 채운 로그인 창**으로 넘어감(가입하며 된 자동 로그인은 풂)
   - 아이디 3 ~ 20자(영문 · 숫자 · `. - @ _`), 비밀번호 8 ~ 26자(영문 · 숫자 · 기호 각 1개 이상, 대문자 필요 없음 — UGS 규칙은 서버로 보낼 때 고정 글자를 붙여 채움)
3. 세이브 맞추기([CloudAccount.cs](../Assets/_Project/Scripts/Meta/Cloud/CloudAccount.cs) `SyncAsync`)

| 이 PC 세이브 | 서버 세이브 | 결과 |
|---|---|---|
| 이 계정 것 | 없음 · 바뀌지 않음 | 그대로 계속(안 올린 변경만 올림) |
| 이 계정 것(안 올린 변경 없음) | 다른 PC에서 더 진행 | 서버 것을 받아 **게임 다시 불러오기** |
| 이 계정 것(안 올린 변경 있음) | 다른 PC에서 더 진행 | 어느 쪽을 쓸지 묻기 |
| 처음 로그인(옛 세이브) | 없음 | **지금 PC 세이브를 이 계정으로 옮김** |
| 처음 로그인, 진행 없음(이름 안 정함) | 있음 | 서버 것을 받음 |
| 처음 로그인, 진행 있음 | 있음 | 어느 쪽을 쓸지 묻기(고르지 않은 쪽은 사라짐) |
| 다른 계정 것 | 있음 / 없음 | 이 계정 서버 세이브로 바꿈 / 처음부터 시작 |

- 서버 세이브: Cloud Save 플레이어 데이터 키 `save` 한 칸 = 세이브 전체 JSON → gzip → base64 (한 칸 한도 5MB)
- 자동 저장: 진행이 바뀌면 마지막 변경 8초 뒤(길어도 60초마다) 올림. 실패하면 30초 뒤 다시. 게임을 끌 때도 시도하고, 못 올린 변경은 표시가 남아 다음 로그인 때 올림
- 로그인 전 게임이 스스로 쓰는 값(행동력 회복 · 하루 초기화 등)은 '변경'으로 보지 않음 → 다른 PC 세이브를 받을 때 쓸데없이 묻지 않음
- 서버 세이브를 받으면 씬을 다시 열어 모든 시스템이 새로 읽음(타이틀은 로고 · TAP 없이 바로 진행). 타이틀 · 튜토리얼 · 오디오 리스너는 씬을 다시 열 때도 생기도록 바꿈
- 설정 창(홈 위 `설정`) 아래 **계정**: 로그인 상태 · 저장 상태, `지금 서버에 저장` · `로그아웃`(게스트면 `로그인하기`)

## 테스트 · 관리

- 서버에 올라간 세이브 보기 · 지우기: Unity Cloud 대시보드 → Cloud Save → **플레이어 데이터**(플레이어 id로 검색), 계정 보기 · 지우기: Player Management
- 편집기 `SubcultureRPG > 데이터 > 내 정보 초기화`는 **이 PC 세이브만** 지움. 같은 계정으로 다시 로그인하면 서버 세이브가 돌아오므로, 완전히 처음부터 하려면 대시보드에서 그 플레이어의 Cloud Save 데이터도 지우거나 새 아이디로 가입
- 한 PC에서 여러 계정 테스트: 설정 → 로그아웃 → 다른 아이디로 로그인
