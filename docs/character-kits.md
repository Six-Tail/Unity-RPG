# 캐릭터 전투 구성 (스킬 · 패시브 · 초월 고유 능력)

캐릭터마다 **기본 공격 · 스킬 · 궁극기 · 고유 패시브 · 초월 고유 능력 3개**가 따로 있습니다.

- 구성표: [CharacterKits.cs](../Assets/_Project/Scripts/Battle/CharacterKits.cs) — 캐릭터 id(`c_violet` …)로 찾고, 표에 없는 캐릭터는 역할별 기본 구성
- 패시브 틀: [Passives.cs](../Assets/_Project/Scripts/Battle/Passives.cs) — 발동 시점(`PassiveTrigger`) × 효과(`PassiveEffect`). 설명 문장은 수치에서 자동 생성(`PassiveText`)
- 유닛 생성: [RuntimeUnits.cs](../Assets/_Project/Scripts/Battle/RuntimeUnits.cs) — 능력치는 성급·역할, 스킬·패시브는 구성표
- 수치는 **스킬 Lv.1 기준**, 레벨당 +10%. 피해 계수는 **타격 1회 기준**(`60% × 3` = 3번 때림)

## 설계 원칙 — 초월과 뽑기 유도

- **고유 패시브가 캐릭터의 핵심**이고, 초월 고유 능력(+1 · +3 · +6)은 그 패시브를 **강화**하는 쪽이 중심입니다. 초월할수록 같은 패시브가 눈에 띄게 좋아집니다.
- **태생 성급이 높을수록 패시브가 특별하고 초월 강화 폭이 큽니다.**

| 태생 | 패시브 | 초월 +1 | 초월 +3 | 초월 +6 |
|---|---|---|---|---|
| **6★** | 전용 메커니즘(연쇄 시전 · 반격 · 화상 연계 등) | 패시브 강화 (+ 추가 효과) | 패시브 강화 + 추가 효과 | 패시브 대폭 강화 + 추가 효과 |
| 5★ | 쓸 만한 발동형 | 능력치 | 패시브 강화 | 패시브 강화 + 추가 효과 |
| 4★ | 단순한 발동형 | 작은 능력치 | 작은 능력치 | 패시브 소폭 강화 |
| 3★ | 소박한 효과 | 작은 능력치 | 작은 능력치 | 패시브 소폭 강화 |

## 초월 보상

| 초월 | 보상 |
|---|---|
| **+1** | 캐릭터 고유 능력 ① |
| +2 | **기본 공격** 레벨 +3 |
| **+3** | 캐릭터 고유 능력 ② |
| +4 | **스킬** 레벨 +3 |
| +5 | **궁극기** 레벨 +3 |
| **+6** | 캐릭터 고유 능력 ③ |

- +2 · +4 · +5의 레벨 +3은 **재료 없이 바로 적용**됩니다. 재료로 올리는 레벨(최대 10)과 별개로 더해져 최대 Lv. 13이 되고, 육성 화면에는 `Lv. 7 +3`처럼 표시됩니다. (`Transcendence.SkillLevelBonus` · `PlayerRoster.EffectiveSkillLevels`)
- 초월 단계당 전 능력치 +5%, 스킬 계수 +5%는 그대로입니다.

## 연쇄 시전 (바이올렛 전용)

적을 처치하면 **스킬을 SP 소모 없이 체력이 가장 낮은 적에게 자동으로 다시 시전**합니다.

- 기본 공격 · 스킬 · 궁극기 어느 것으로 처치해도 발동합니다. 다시 시전한 스킬로 또 처치하면 이어집니다(연쇄).
- 다시 시전할 때마다 피해가 줄어듭니다: 1번째 **-20%**, 2번째 **-40%**, 연쇄 최대 2회.
- 처치하지 못하거나 연쇄가 끝나면 피해 감소는 **원래대로** 돌아옵니다(다음 처치 때 다시 -20%부터).
- 초월하면 피해 감소가 줄어듭니다.

| 초월 | 1번째 | 2번째 | 연쇄 최대 |
|---|---|---|---|
| 기본 | -20% | -40% | 2회 |
| +1 | -15% | -30% | 2회 |
| +3 | -10% | -20% | 2회 |
| +6 | -5% | -10% | **3회** |

전투 화면에서는 행동자 위에 `연쇄 시전 1회 피해 -20%`가 뜹니다. 구현: `PassiveEffect.Recast` · `BattleEngine.NextRecast` · `BattleController.Recasts`.

## 공격 방식

| 방식 | 설명 |
|---|---|
| 단일 / 전체 | 적 1명 / 적 전체 |
| **다단 히트** | 같은 대상을 여러 번 타격. 타격마다 치명타·브레이크 게이지가 따로 계산됨 |
| **확산** (`Blast`) | 고른 적 1명 + 양옆. 양옆은 `splash` 비율만큼 |
| **연타** (`RandomEnemies`) | 타격마다 살아 있는 적 중 무작위. 대상 선택 없이 바로 발동 |
| 흡혈 / 행동 당김 / 디버프 해제 / 자신 효과 | 스킬에 붙는 추가 동작(`lifesteal` · `advance` · `cleanse` · `selfEffect`) |

## 상태 효과 (추가분)

| 효과 | 내용 |
|---|---|
| 속도 증가 / 감소 | 다음 행동 순서가 빨라짐 / 느려짐 |
| 치명타 확률 증가 | 치명타 확률 + |
| 재생 | 자기 턴 시작마다 회복(건 유닛의 공격력 기준) |
| **도발** | 적의 단일 대상 공격이 이 유닛에게 향함(전체·연타 공격은 제외) |
| **기절** | 다음 자기 턴에 행동 불가. 풀린 뒤 2턴 동안은 다시 걸리지 않음 |

아이콘 그림: `Resources/Art/Status/{SpdUp|SpdDown|CritUp|Regen|Taunt|Stun}.png` (없으면 글자 아이콘 `속` · `치` · `생` · `도` · `절`).

## 패시브 발동 표시

- 발동하면 그 유닛 위에 `패시브 · 이름`이 뜹니다.
- **추가 공격 / 반격**: 본 공격이 끝난 뒤 머리말(`추가 공격` · `반격`)이 붙은 피해 숫자로 표시. 여기서 처치해도 처치 패시브는 발동하지 않습니다.
- **추가 행동**(카엘 +6): 바로 한 번 더 행동. 추가 행동 중에는 다시 얻을 수 없고, 버프 턴·지속 피해도 진행되지 않습니다.
- `(턴당 N회)` = 자기 턴과 다음 자기 턴 사이에 N번까지.

## 새 캐릭터 추가

`CharacterKits.BuildAll()`에 한 항목을 추가합니다.

```csharp
["c_newchar"] = K(
    Atk("기본 공격 이름", One, 0.5f, 2),                       // 적 1명 50% × 2회
    Atk("스킬 이름", Blast, 1.4f).Splash(0.5f),                // 확산
    Sup("궁극기 이름", Party).Heal(1.3f).Cleanse(),            // 아군 전체 회복 + 해제
    A("패시브 이름", T(Crit, PassiveEffect.Energy, 8, limit: 1)),
    A("+1 능력", S(PassiveEffect.CritRate, 0.08f)),                          // 추가 효과만
    A("+3 능력").Up(T(Crit, PassiveEffect.Energy, 11, limit: 1)),            // 패시브 강화만
    A("+6 능력", S(PassiveEffect.HitsSkill, 1)).Up(T(Crit, PassiveEffect.Energy, 15, limit: 1))),   // 둘 다
```

- `A("이름", 효과…)` = 추가 효과, `.Up(효과…)` = 고유 패시브를 이 효과들로 **교체**(강화판). 가장 높은 해금 단계의 강화판이 적용됩니다.
- 연쇄 시전은 `Re(1번째 감소, 2번째 감소, 최대 횟수)`.
- 설명 문장은 자동으로 만들어집니다.
