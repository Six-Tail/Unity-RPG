# 친구 · 길드

홈 오른쪽 아래 타일 `길드` · `친구`에서 들어갑니다. 가상 지휘관 · 가상 길드(번호로 늘 같은 모습을 만들어 냄)와 실제 플레이어(친구 · 길드 — 로그인 필요)가 함께 나옵니다. 나중에 서버를 붙이면 데이터 클래스만 바꾸면 됩니다.

- 가상 지휘관: [Commanders.cs](../Assets/_Project/Scripts/Meta/Social/Commanders.cs) — 결투장 랭킹 · 친구 · 길드원이 함께 씀. UID(8자리) = 10000000 + 번호
- 친구: [PlayerSocial.cs](../Assets/_Project/Scripts/Meta/Social/PlayerSocial.cs)
- 길드: [PlayerGuild.cs](../Assets/_Project/Scripts/Meta/Social/PlayerGuild.cs)
- 화면: [SocialScreens.cs](../Assets/_Project/Scripts/Meta/UI/SocialScreens.cs) (`FriendScreen` · `GuildScreen`)

## 친구

| 항목 | 내용 |
|---|---|
| 정원 | 30명 |
| 탭 | `친구`(인사 · 삭제) / `받은 신청`(수락 · 거절) / `친구 찾기`(UID 검색 · 추천 6명 · 추천 새로고침) |
| 추가 | 추천 또는 UID 8자리 검색 → `친구 추가` (바로 수락됨) |
| UID 검색 | 로그인 중이면 **먼저 서버에서 실제 플레이어**를 찾음(공개 키 `uid`, 인덱스 `uid` 필요) → `● 플레이어` 줄. 없으면 그 UID의 가상 지휘관(실제 UID와 가상 UID가 같은 8자리 범위라 서버를 먼저 봄) |
| 실제 플레이어 친구 | **신청 → 상대가 `받은 신청`에서 수락해야 친구**(양쪽 목록에 들어감). 친구 탭 맨 위, 줄을 누르면 지휘관 정보창. 인사 보상은 같음. 서버를 못 읽으면 저장된 이름 · UID로 표시 |
| 친구 신청(실제 플레이어) | 검색 결과 · 지휘관 정보창의 `친구 신청` → `받은 신청` 탭 아래 **보낸 신청**(수락 대기 · `신청 취소`). 보낸 신청은 동시에 **3명까지**. 서로 신청하면 바로 친구 |
| 받은 신청(실제 플레이어) | `수락` → 바로 친구, 보낸 사람은 다음 동기화 때 확정 · `거절` → 보낸 사람의 신청이 지워짐. 홈 `친구` 타일 알림에 포함 |
| 삭제 | 내가 지우면 상대 목록에서도 다음 동기화 때 지워짐 |
| 동기화 | 로그인 중 2분마다 + 친구 화면을 보는 동안 30초마다(`FriendLink`). 수락 · 거절 소식은 친구 화면 알림으로 |

서버 구조(서버 함수 없이 각자 자기 공개 데이터만 씀, [FriendLink.cs](../Assets/_Project/Scripts/Meta/Cloud/FriendLink.cs)): 신청 = 내 `fr_to0 · fr_to1 · fr_to2`에 상대 id → 상대가 `fr_toN == 내 id`로 검색 · 수락 = 내 `fr_list`(친구 id 목록)에 넣음 → 보낸 사람이 그걸 읽고 확정 · 거절 = `fr_dec`. 가상 지휘관은 지금처럼 신청하면 바로 수락.
| 받은 신청 | 날마다 1 ~ 2건(처음 2건), 최대 5건 보관 |
| 인사 | 친구마다 하루 1번(05:00 초기화) → **행동력 +2 · 금화 +500**. `모두 인사`로 한 번에 |

**친선 전투**: 친구 목록 줄의 `친선 전투` 또는 지휘관 정보창(친구 · 랭킹 · 길드원)의 `친선 전투` → 편성 → `대결!`. 상대는 그 지휘관의 **전투력 상위 4명**이 키운 그대로(레벨 · 성급 · 초월 · 스킬 · 장비 · 호감도, `SnapStats.BuildUnit`) 나오고 AI가 조종. 실제 플레이어는 마지막 접속 때 올린 공개 프로필 기준. 도전권 · 행동력 없음, 점수 · 보상 없음, 결과 화면 `다시`로 재대결(이번 상대와의 승패 표시). 끝나면 요청한 화면으로 돌아감. 코드: [FriendlyBattle.cs](../Assets/_Project/Scripts/Meta/Modes/FriendlyBattle.cs).

**지휘관 정보창**: 친구 · 받은 신청 · 친구 찾기 · 길드원 목록과 결투장 `랭킹`에서 다른 지휘관의 줄을 누르면 열립니다 — 테두리 · 아바타 · 이름 · 칭호 · 레벨 · UID · 마지막 접속 · 전투력 · 인사말 · **대표 파티 4명**(성급 · 속성 · 역할 · 레벨) · `친구 추가`. 랭킹에서 열면 결투장 순위 · 티어 · 점수도 표시. 랭킹의 지휘관도 친구 · 길드와 같은 생성기(`Commanders.FromSeed`)로 만들어, 어디서 열어도 같은 사람입니다. 코드: [PlayerInfoWindow.cs](../Assets/_Project/Scripts/Meta/UI/PlayerInfoWindow.cs).

홈 타일에 `●N` = 받은 신청 + 아직 인사하지 않은 친구 수. 테스트: Player Social 컴포넌트 ⋮ → `테스트: 하루 넘기기`.
