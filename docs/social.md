# 친구 · 길드

홈 오른쪽 아래 타일 `길드` · `친구`에서 들어갑니다. 서버가 없으므로 상대 지휘관과 길드는 **가상**입니다(번호로 늘 같은 모습을 만들어 냄). 나중에 서버를 붙이면 데이터 클래스만 바꾸면 됩니다.

- 가상 지휘관: [Commanders.cs](../Assets/_Project/Scripts/Meta/Social/Commanders.cs) — 결투장 랭킹 · 친구 · 길드원이 함께 씀. UID(8자리) = 10000000 + 번호
- 친구: [PlayerSocial.cs](../Assets/_Project/Scripts/Meta/Social/PlayerSocial.cs)
- 길드: [PlayerGuild.cs](../Assets/_Project/Scripts/Meta/Social/PlayerGuild.cs)
- 화면: [SocialScreens.cs](../Assets/_Project/Scripts/Meta/UI/SocialScreens.cs) (`FriendScreen` · `GuildScreen`)

## 친구

| 항목 | 내용 |
|---|---|
| 정원 | 30명 |
| 탭 | `친구`(인사 · 삭제) / `받은 신청`(수락 · 거절) / `친구 찾기`(UID 검색 · 추천 6명 · 추천 새로고침) |
| 추가 | 추천 또는 UID 8자리 검색 → `친구 추가` (가상이라 바로 수락됨) |
| 받은 신청 | 날마다 1 ~ 2건(처음 2건), 최대 5건 보관 |
| 인사 | 친구마다 하루 1번(05:00 초기화) → **행동력 +2 · 금화 +500**. `모두 인사`로 한 번에 |

홈 타일에 `●N` = 받은 신청 + 아직 인사하지 않은 친구 수. 테스트: Player Social 컴포넌트 ⋮ → `테스트: 하루 넘기기`.

## 길드

| 항목 | 내용 |
|---|---|
| 가입 | 추천 길드 8곳(날마다 · 새로고침으로 바뀜) 중 지휘관 레벨 조건이 맞는 곳에 바로 가입 |
| 창설 | 이름 2 ~ 8자, 금화 50,000. 내가 길드장, 길드원 5명으로 시작 |
| 출석 | 하루 1번: 금화 5,000 × (1 + 길드 레벨당 10%) + 크리스탈 10, 길드 경험치 +20, 기여도 +20 |
| 기부 | 하루 3번: 금화 10,000 → 크리스탈 5, 길드 경험치 +50, 기여도 +50 |
| 길드 레벨 | 최대 Lv.10, 다음 레벨까지 1,000 × 레벨. 길드원들도 날마다 경험치를 쌓음(길드원 수 × 12) |
| 길드원 | 최대 30명. 목록은 주간 기여도 순(길드장 · 부길드장 · 길드원), 내 기여도는 매주 월요일 05:00 초기화 |
| 탈퇴 | `탈퇴` → 확인 |

홈 타일에 `●1` = 오늘 출석 전. 테스트: Player Guild 컴포넌트 ⋮ → `테스트: 하루 넘기기` · `테스트: 길드 경험치 +500`.
