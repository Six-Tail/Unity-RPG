## 설계안

서버 함수 없이 각자 자기 Cloud Save **공개 데이터**만 씁니다(친구 신청 `FriendLink`와 같은 방식).

| 데이터 | 누가 씀 | 내용 |
|---|---|---|
| `g_info` | 길드장 | 길드 이름 · 소개 · 가입 방식 · **길드원 목록** · 거절 목록 |
| `g_id` | 모든 길드원 | 내가 속한 길드 id → 길드원 찾기 |
| `g_open` | 길드장 | 모집 중이면 표시 → 추천 · 검색 |
| `g_req` | 가입 신청자 | 신청한 길드 id → 길드장이 신청 목록을 찾음 |
| `g_xp` | 모든 길드원 | 기여도(이번 주 · 누적) → 길드 경험치 = 합 |

- 가입: 신청 → 길드장이 수락하면 목록에 추가 → 신청자가 다음 동기화 때 확인하고 가입 완료
- 탈퇴 · 추방 · 해산은 상대가 다음 동기화 때 감지
- 출석 · 기부 보상 수치는 지금 그대로, 길드 레벨은 길드원 기여도 합으로
- **길드 채팅**: Vivox 채널 `guild_{길드 id}`
- 로그인 필요(게스트는 길드 불가). 길드장 위임은 다음 버전
