# 장비

캐릭터마다 **6부위**에 장비를 1개씩 장착합니다. 장비마다 **성급(3~6★)**, **주옵션 1줄 + 보조 옵션 3~4줄**이 있고, 같은 세트를 **2개 / 4개** 장착하면 세트 효과가 발동합니다.

## 성급 (= 아이템 등급)

별 색은 등급 색입니다: **3★ 고급(초록) · 4★ 희귀(파랑) · 5★ 영웅(보라) · 6★ 전설(금색)**.

| 성급 | 최대 강화 | 보조 옵션 강화 횟수 (4강마다) | 수치 배율 | 분해 기본 강화석 |
|---|---|---|---|---|
| 3★ | **+9** | 2회 (+4, +8) | 50% | 1 |
| 4★ | **+12** | 3회 (+4, +8, +12) | 65% | 2 |
| 5★ | **+16** | 4회 | 80% | 3 |
| 6★ | **+20** | 5회 | 100% | 5 |

- 수치 배율은 주옵션·보조 옵션 모두에 적용(아래 표는 6★ 기준). 주옵션은 그 성급의 최대 강화에서 최대치에 도달합니다.
- 태생 3옵션 장비는 +4에서 새 옵션이 붙으므로 실제 상승 횟수는 1회 적습니다.
- 예전 세이브의 장비(성급 정보 없음)는 6★로 취급합니다.

| 파일 | 역할 |
|---|---|
| [EquipmentData.cs](../Assets/_Project/Scripts/Meta/Equipment/EquipmentData.cs) | 부위·옵션 종류, 주/보조 옵션 수치, 세트 10종, 생성·강화·능력치 합산 규칙 |
| [PlayerEquipment.cs](../Assets/_Project/Scripts/Meta/Equipment/PlayerEquipment.cs) | 보유 장비 저장(PlayerPrefs `equipment`), 장착·해제·교체·강화·잠금·분해 |
| [EquipmentPanel.cs](../Assets/_Project/Scripts/Meta/UI/EquipmentPanel.cs) | 육성 화면 `장비` 버튼으로 여는 장비 패널 |
| [StatBonus.cs](../Assets/_Project/Scripts/Battle/StatBonus.cs) | 장비 능력치 → 전투 유닛(최종치 = 레벨 기준치 × (1 + %) + 고정치) |

## 부위와 주옵션

| 부위 | 주옵션 후보 |
|---|---|
| 머리 | 체력 (고정) |
| 손 | 공격력 (고정) |
| 몸 | 체력% · 공격력% · 방어력% · 치명타 확률 · 치명타 피해 · 치유량 · 효과 명중 |
| 발 | 체력% · 공격력% · 방어력% · 속도 |
| 목걸이 | 체력% · 공격력% · 방어력% · 물리/화염/얼음/번개/바람 피해 |
| 반지 | 체력% · 공격력% · 방어력% · 브레이크 효율 · 에너지 회복 · 방어 관통 |

주옵션은 강화할 때마다 일정하게 오릅니다(6★ 기준 +0 → +20).

| 주옵션 | +0 | +20 |
|---|---|---|
| 체력 / 공격력 | 110 / 55 | 1,500 / 300 |
| 체력% · 공격력% · 속성 피해 · 효과 명중 | 4% | 40% |
| 방어력% | 5% | 50% |
| 속도 | 3 | 25 |
| 치명타 확률 / 치명타 피해 | 3% / 6% | 30% / 60% |
| 치유량 | 3.5% | 35% |
| 브레이크 효율 / 에너지 회복 / 방어 관통 | 6% / 2% / 2.5% | 60% / 18% / 25% |

## 보조 옵션

후보: 체력 · 체력% · 공격력 · 공격력% · 방어력 · 방어력% · 속도 · 치명타 확률 · 치명타 피해 · 브레이크 효율 · 효과 명중 · 효과 저항 · 방어 관통 (주옵션과 같은 옵션·중복 제외)

- 태생 **3옵션**(75%) 또는 **4옵션**(25%).
- **4강마다**(+4 / +8 / +12 / +16 / +20) 보조 옵션 1회:
  - 3옵션 장비 → +4에서 **새 보조 옵션 1줄 추가**(4줄이 됨), 이후 +8~+20에 4회 상승.
  - 4옵션 장비 → +4~+20에 **5회** 무작위 1줄 상승.
- 1회 상승치 = 최대치(× 성급 배율)의 80 / 90 / 100% 중 무작위 (체력 40 · 공격력/방어력 20 · 체력%/공격력%/효과 명중/효과 저항 4% · 방어력% 5% · 속도 2.5 · 치명타 확률 3% · 치명타 피해/브레이크 효율 6% · 방어 관통 2.5%).
- 상세의 `●` 개수 = 그 옵션이 오른 횟수.
- 4강마다라서 3★(+9)·5★(+16)는 마지막 몇 강에는 보조 옵션 변화가 없습니다(상세에 `남은 보조 옵션 강화 없음` 표시).

## 세트 (10종)

| 세트 | 2세트 | 4세트 (2세트에 더해) | 드롭 |
|---|---|---|---|
| 맹공의 문장 | 공격력 +12% | 치명타 확률 +12% | 장비 던전 ① |
| 수호의 서약 | 방어력 +15% | 체력 +12% · 효과 저항 +15% | 장비 던전 ① |
| 화염의 낙인 | 화염 피해 +10% | 화염 피해 +15% · 치명타 피해 +16% | 장비 던전 ② |
| 서리의 결정 | 얼음 피해 +10% | 얼음 피해 +15% · 효과 명중 +15% | 장비 던전 ② |
| 뇌명의 인장 | 번개 피해 +10% | 번개 피해 +15% · 방어 관통 +10% | 장비 던전 ③ |
| 질풍의 깃털 | 바람 피해 +10% | 바람 피해 +15% · 속도 +8 | 장비 던전 ③ |
| 강철의 의지 | 물리 피해 +10% | 물리 피해 +15% · 브레이크 효율 +20% | 장비 던전 ④ |
| 파쇄의 망치 | 브레이크 효율 +16% | 브레이크 효율 +24% · 방어 관통 +8% | 장비 던전 ④ |
| 생명의 샘 | 치유량 +10% | 에너지 회복 +10% · 전투 시작 에너지 +20 | 장비 던전 ⑤ |
| 신속의 바람 | 속도 +6 | 공격력 +10% · 전투 시작 에너지 +15 | 장비 던전 ⑤ |

6부위라 **4세트 + 2세트** 조합이 가능합니다.

## 전투 반영 (새 능력치)

| 능력치 | 효과 |
|---|---|
| 방어 관통 | 대상 방어력을 그 비율만큼 무시(최대 80%) |
| 속성 피해 | 같은 속성 스킬의 피해 증가 |
| 브레이크 효율 | 브레이크 게이지 감소량 · 브레이크 추가 피해 증가 |
| 에너지 회복 | 행동으로 얻는 에너지 증가(필살기 회전) |
| 치유량 | 회복량 증가 |
| 효과 명중 / 효과 저항 | 적에게 거는 효과 확률 증가 / 받는 해로운 효과 확률 감소 |
| 전투 시작 에너지 | 세트 효과(생명의 샘·신속의 바람) |

육성 화면 능력치(HP/ATK/DEF/SPD)는 장비를 포함해 표시되고, 장비로 오른 만큼 `(+N)`이 초록색으로 붙습니다.

## 장비 초월

최대 강화(3★ +9 · 4★ +12 · 5★ +16 · 6★ +20)에 도달한 장비는 **초월 +1 ~ +5**가 가능합니다.

| | 내용 |
|---|---|
| 재료 | **같은 세트 · 같은 부위 · 같은 성급** 장비 1개(미장착·미잠금, 가장 낮은 강화부터 자동 선택) + 금화 `5,000 × (성급-2) × 다음 단계` |
| 보정 | 단계마다 **주옵션 +6%** · **보조 옵션 +4%** (+5 = 주옵션 +30% · 보조 +20%) |
| 표시 | 캐릭터 초월처럼 앞에서부터 초월 단계만큼 별이 **무지개 색**, 뒤에 `+N` |
| 환급 | 재료 장비에 투입했던 강화석의 60%를 돌려받음 |

## 강화 · 분해

| | 비용 / 결과 |
|---|---|
| +N → +N+1 | 금화 `500 + 250×N` · 장비 강화석 `1 + N/4` |
| +0 → +20 합계 | 금화 57,500 · 강화석 60 (장비 1개) |
| 분해 | 장비 강화석 `2 + 투입 강화석의 60%` (잠금·장착 중이면 불가, 두 번 눌러 확인) |

- 패널 버튼: `강화 +1` · `+N까지 강화`(다음 4강 단위까지 한 번에, 비용이 모자라면 거기서 멈춤).
- 장비 강화석은 **장비 던전**과 분해로 얻습니다. 가방에서 보유량 확인.

## 장비 패널 (육성 → 캐릭터 → `장비`)

- **왼쪽**: 6부위 장착 칸(세트 색 · 주옵션 · 강화 수치) — 칸을 누르면 그 부위 목록. 아래에 장비 능력치 합계와 세트 효과(발동 = 밝게).
- **가운데**: 선택 부위 보유 장비. 이 캐릭터 장착 → 미장착 → 다른 캐릭터 장착 순, 강화 높은 순. 잠금·장착자 표시.
- **오른쪽**: 상세(주옵션, 보조 옵션 `●` 상승 횟수, 다음 보조 옵션 강화 단계, 세트 효과, 비용)와 `장착/장착 해제` · `잠금` · `강화` · `분해`.
- 다른 캐릭터가 낀 장비를 장착하면 **서로 맞바꿉니다**(그 캐릭터는 이 캐릭터가 끼던 같은 부위 장비를 받음).

## 자동 장착

편성 화면 아래 오른쪽 **`장비 자동 장착`** — 선택한 파티의 캐릭터마다(출전 순서대로) 전투력이 가장 높아지는 조합으로 장비를 바꿔 낍니다.

- 후보: **장착하지 않은 장비 + 그 캐릭터가 이미 낀 장비**. 다른 캐릭터가 낀 장비는 건드리지 않습니다(앞 순서 캐릭터가 좋은 장비를 먼저 가져감).
- 부위마다 하나씩 바꿔 보며 전투력(호감도 보너스 포함)이 오르면 채택, 세트 효과(2 · 4세트)까지 맞추려고 두 번 훑습니다.
- 결과 창에 캐릭터별 바꾼 부위 수와 전투력 변화.
- 코드: `PlayerEquipment.AutoEquip`, 계산은 `CombatPower.EvaluatorFor`(유닛 데이터를 한 번만 만들고 장비만 바꿔 계산).

## 장비 던전 (특수 던전 탭)

세트 2종씩 묶은 던전 **5곳**(①~⑤)이 각각 **1~5단계**를 가집니다(총 25칸, 줄 = 던전, 칸 = 단계). 단계가 높을수록 드롭 성급이 오릅니다.

| 던전 | 세트 |
|---|---|
| ① | 맹공의 문장 · 수호의 서약 |
| ② | 화염의 낙인 · 서리의 결정 |
| ③ | 뇌명의 인장 · 질풍의 깃털 |
| ④ | 강철의 의지 · 파쇄의 망치 |
| ⑤ | 생명의 샘 · 신속의 바람 |

| 단계 (모든 던전 공통) | 개방 (쉬움) | 적 레벨 | 드롭 성급 | 매 클리어 |
|---|---|---|---|---|
| 1단계 | 2-6 | Lv.11~13 | 80% 3★ · 20% 4★ | 장비 ×2 · 강화석 ×3 · 금화 2,000 |
| 2단계 | 4-6 | Lv.22~24 | 55% 3★ · 45% 4★ | 장비 ×2 · 강화석 ×5 · 금화 3,500 |
| 3단계 | 7-6 | Lv.38~40 | 30% 3★ · 70% 4★ | 장비 ×2 · 강화석 ×7 · 금화 5,500 |
| 4단계 | 10-6 | Lv.55~57 | 10% 3★ · 50% 4★ · 40% 5★ | 장비 ×2 · 강화석 ×10 · 금화 8,000 |
| 5단계 | 13-6 | Lv.71~73 | 35% 4★ · 45% 5★ · 20% 6★ | 장비 ×2 · 강화석 ×14 · 금화 11,000 |

- **3단계까지 최대 4★, 4단계 최대 5★, 5단계 최대 6★.**
- 드롭 장비: 두 세트 중 하나 · 부위·주옵션·보조 옵션 무작위. 결과 화면에 성급과 함께 표시됩니다.
- 수치는 `StageContent.EquipTierRarity`(성급 확률) · `EquipTierChapters`(개방)에서 조정.

**테스트**: 육성 화면 `재료·금화·장비 충전(테스트)` (장비 12개 + 강화석 200 + 금화 10만) · Meta → Player Equipment ⋮ `테스트: 장비 30개 지급` / `장비 전부 삭제`.
