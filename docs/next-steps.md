## 2. Unity에서 아직 직접 확인하지 못한 것

마지막 UI 개편분(오프라인 컴파일만 통과):
- [ ] **팝업 공통 틀**: 모든 창의 남색 머리띠 · 금색 구분선 · 제목 아이콘. 창 안 내용이 머리띠에 가리지 않는지(지휘관 정보 · 채팅 · 장비 제작 · 옷장 · 호감도 · 설정 · 로그인)
- [ ] **우편함**: 보상 아이콘 칸(최대 4칸, 넘치면 `+N`)
- [ ] **시즌 패스**: 줄 이름 칸 아이콘 · 단계 알약 · 지금 단계 세로 띠 · 칸(아이콘 + 수량 + 이름)
- [ ] **프로필**: 금색 테두리 · 위쪽 머리 배경 · 하위 창 머리띠(처음 이름 정하기 포함)
- [ ] **도감**: 세로 성급 탭 · 수집 보상 · 속성 필터 · 카드 · 상세
- [ ] **편성**: 순서 배지 숫자가 방패 정가운데인지(마지막 조정 후 미확인) · 전투력 정렬 · 속성 칩 아이콘
- [ ] **결투장**: 상대 전투력이 쉬움 < 보통 < 어려움 순서인지(새로고침 여러 번)
- [ ] **안내 문구 정리**: 문구를 뺀 자리(장비 던전 상세 · 무한의 탑 · 파견 · 길드 등)가 어색하게 비지 않는지
- 테스트 체크리스트는 각 화면 문서(docs/codex.md · main-hub.md · rewards.md · modes.md · dispatch-tower.md · social.md · guild.md) 참고

## 3. 빌드 · 기기 확인

- [ ] **안드로이드 APK 다시 빌드 → 휴대폰 설치**: 출시 설정 적용 → Build(테스트 APK는 한 파일).
  - 노치 · 상태 표시줄 숨김, 팝업이 오른쪽으로 밀리지 않는지(카메라 쪽까지 어두운 막)
  - 개편한 모든 화면을 휴대폰 화면비로(왼쪽 탭 · 오른쪽 상세가 잘리지 않는지)
- [ ] **PC(Windows) 빌드**: IL2CPP는 **Windows 11 SDK** 필요 — Visual Studio Installer → C++ 데스크톱 개발 → Windows 11 SDK 체크(회사 PC엔 없었음. 집 PC에 있으면 바로 빌드)
